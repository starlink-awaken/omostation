# `.mimocode` 命令资产

`.mimocode/` 是本地 Mimocode 会话分析与工作流蒸馏资产目录，不是运行时代码目录，也不是主仓公共 CLI 的替代入口。

## 边界

- `commands/` 只保存只读分析或蒸馏命令说明；不得在这里放需要部署、写入生产状态或修改 SSOT 的脚本。
- 可复用的工程能力必须下沉到对应 `projects/*` 子项目；跨项目治理能力进入 `bin/`，并登记到工具清单与持续审计入口。
- 临时实验、个人配置和数据库不纳入仓库；命令文档不得要求提交本机数据库、缓存或凭据。
- 新增命令必须说明输入、输出、读写边界和归属；若长期保留，应同步更新根仓工具索引或对应子项目文档。

## 维护

变更前阅读 [AGENTS.md](AGENTS.md)。根仓目录治理会把本目录视为受治理的只读工作流资产，并检查其说明文件是否存在。
