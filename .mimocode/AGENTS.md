# `.mimocode` Agent Guide

## 用途

本目录只承载 Mimocode 的命令说明和只读轨迹分析入口。它不是 Python 包、服务、CI 执行目录，也不拥有任何业务 SSOT。

## 修改规则

- 只允许新增或修改命令说明、边界说明和索引文档。
- 命令默认必须只读；需要写入的能力必须迁移到 `bin/` 或明确 owner 的 `projects/*` 子项目。
- 不提交本地数据库、缓存、会话内容、凭据或机器相关路径。
- 命令引用的路径、工具和数据库必须注明不可用时的失败行为，避免把个人环境假设伪装成仓库能力。
- 新命令先判断是否与 `bin/`、`scripts/` 或子项目已有能力重复；重复能力必须复用或下沉，不得复制一份。

## 验证

文档变更至少运行根仓文档 SSOT 检查和根目录治理检查。若命令说明涉及新的公共入口，还必须同步更新对应工具清单与 `bin-scripts-convergence-audit` 证据。
