# Decision: Agent 分支命名空间隔离

为并发 agent 分支引入 `agent/{actor_id}/` 命名空间前缀，与人工 `work/` 分支物理隔离。

关键设计决策：
- 通过环境变量 `AGENT_ACTOR_ID` 或 CLI `--actor-id` 参数区分 agent vs 人类调用
- agent 分支 TTL 7 天自动清理
- 向后兼容：无 actor-id 时保持 work/ 前缀
