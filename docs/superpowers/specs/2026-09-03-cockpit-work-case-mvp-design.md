# Cockpit 个人工作案件台 MVP

## 决策

Cockpit 从系统页面集合收敛为夏明星个人的工作案件台。MVP 先交付“数据调查—催办—汇总—上报—OA 结案”闭环；OA 仍是正式任务状态权威，OMO 仍是任务、审批、动作和回执真值，Documents 只保存文书与归档事实。

## 用户旅程

1. 已登录 OA 会话发现任务，生成不产生外部动作的案件草稿。
2. 系统归集材料、检索历史资料、判定任务和敏感等级，并生成执行方案。
3. 用户一次确认方案；此后内部步骤可推进，但任何外部发送、OA 回写或向上报送仍需最终确认。
4. 调查包可混用在线表单、Excel/Word 和盖章 PDF/扫描件。
5. 每单位保留补交版本链，最后一份确认有效的材料参与汇总；完整且校验通过后自动归档。
6. 到期后形成未交、无效和待补清单，生成可批次确认的催办动作。
7. 系统形成汇总、上报文稿、附件包和领导确认话术；获得外部动作确认、回执和 OA 回读后结案。

## 权威与边界

- Cockpit 是人机入口、投影和确认界面，不建立第二任务、知识、凭据或流程真值。
- OMO 扩展 `WorkCase`、`CaseStep`、`Submission`、`OutboundAction`、`ApprovalGrant` 和 `EvidenceReceipt`；案件绑定 OMO 父任务和 OA 来源引用。
- Iris 负责 OA 会话发现、读取与下载；任何 OA 写入必须由 OMO 受控动作包装，并在执行后回读验证。
- 邮件、微信和在线表单都是外部通道适配器。微信只承担提醒、确认卡和人工半自动执行，不可静默外发。
- KEMS 接收证据引用和质量结论，不接收高敏原始正文；Documents 保存归档原件和材料版本。

## 安全与确认机制

- 低敏内容可路由云端模型；中敏内容先在本地脱敏；高敏或无法判定内容仅走本地模型。
- 人工敏感性例外为案件级、一次性、带原因、有效期和审计记录。
- Cockpit 只显示凭据引用、范围与健康状态。AetherForge/Keychain 在短生命周期适配器进程中注入实际凭据；禁止密码、令牌、私钥和原始高敏内容进入 Git、Documents 非归档区、日志或云端提示词。
- 每个外部动作执行 `propose → preview → human_confirm → execute → re_read → receipt`。确认快照绑定收件人、正文、附件哈希、有效期；内容变更自动失效。批量确认共享批准，但每个收件人单独记录回执。

## MVP 表面

一级导航固定为“今日、案件、工作台、知识与归档、系统与连接”。既有监控、日志、拓扑、调试和治理页面保留链接兼容，但迁入“专家工具”。

案件工作台显示任务摘要、方案、材料、调查对象、调查包、回收与补交、汇总、文稿、外部动作、回执与归档。右侧固定呈现待确认动作、异常、风险和无法自动化时的人工操作卡。移动端先支持案件摘要、异常、批准批次和资料查看。

## 外部接口

- `GET/POST /api/work-cases`：案件查询和草稿创建。
- `GET /api/work-cases/{id}/timeline`：案件步骤、材料、版本与证据投影。
- `POST /api/work-cases/{id}/approvals`：方案或外部动作确认；不得直接执行写入。
- `POST /api/work-cases/{id}/outbound-actions/{action_id}/execute`：仅接受仍有效的批准，并返回回读后的动作回执。
- `POST /api/work-cases/{id}/submissions`：记录在线、邮件或文件回收的版本；仅适配器可写入。

## 非目标

- 不在 MVP 创建多租户、多人协作、公开应用商店客户端或新的调度器/工作流引擎。
- 不自动发送外部消息、自动 OA 回写、自动上报或自动启用凭据。
- 不将现有 OA 直接 CDP 提交方法暴露为前端能力。
- 未有已验证邮箱 API、可达表单域名或已确认 OA 页面选择器时，只交付假适配器、人工操作卡和明确的未启用状态，不伪称自动化完成。

## 验收标准

1. 一个脱敏演练案件可完成 OA 读取、方案生成、一次方案确认、混合调查包、补交版本链、催办、汇总、上报草稿、自动归档和 OA 回读的全链路。
2. 任一外部写入无有效确认或确认快照失效时均被拒绝，且不产生副作用。
3. 低/中/高敏路径、凭据引用隔离、每位收件人回执和人工接管均有可重复测试。
4. Cockpit 主导航不再把技术工具作为默认工作入口；后端不可用时页面明确显示不可用，而不展示演示成功结果。
5. 所有真实外部通道在启用前通过健康、权限、读写回执和人工确认验证；首次真实运行仅使用用户批准的低风险案件。

## 回滚

关闭案件模板和通道描述符即可阻断新动作；已产生的证据与材料版本保持追加可读，不伪造删除。UI 可回退到专家工具入口，外部适配器回退为只读和人工操作卡。
