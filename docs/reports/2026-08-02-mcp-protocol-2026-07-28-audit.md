# MCP 协议 2026-07-28 版本调研与 agora 适配评估

> **创建时间**：2026-08-02

## 1. 执行摘要

**Anthropic 已于 2026-07-28 发布 MCP 协议重大新版本 `2026-07-28`**（stable），是一次**架构级变更**（去握手、去状态化），不是小补丁。但**主流客户端当前均未跟进**：官方 TypeScript SDK 仍锁定 `2025-11-25`，Claude Code / Cursor / Cline 等 TS 生态客户端尚未支持新协议。

**对 agora 的结论：当前无需升级，保持 mcp 1.28.0 + fastmcp 3.4.2 稳定版为最佳状态。** 升级实验已验证可行（改动极小、回归全绿），可作为预演保留，但不应合入。

## 2. 协议 2026-07-28 重大变更

| 变更 | 内容 | 影响 |
|---|---|---|
| **移除 initialize 握手** | 协议改为无状态，每请求经 `_meta` 携带 `protocolVersion`/`clientCapabilities`；版本不匹配返回 `UnsupportedProtocolVersionError`（SEP-2575） | 🔴 breaking |
| **移除协议级 session** | 删除 `Mcp-Session-Id` 头；`tools/list` 等不再按连接变化；跨调用状态用显式 server-minted handles（SEP-2567） | 🔴 breaking |
| **新增 `server/discover`** | 服务器 MUST 实现，通告支持的协议版本/能力/身份；客户端可握手前调用做版本预选（SEP-2575） | 🟡 新增 |
| **移除 ping/logging/setLevel/roots list_changed** | 日志级别改经 `_meta.logLevel` 每请求传递 | 🟡 移除 |
| **subscriptions/listen** | 替代 HTTP GET + `resources/subscribe`，单一长连 POST 流 | 🟡 变更 |
| **resultType 必填 + MRTR** | 所有结果带 `resultType: complete\|input_required`；引入 Multi Round-Trip Requests（SEP-2322） | 🟡 新增 |
| **tasks 移出核心** | 改为官方扩展 `io.modelcontextprotocol/tasks`（SEP-2663） | 🟢 移动 |
| **移除 SSE 可恢复性** | 删除 Last-Event-ID 与 SSE event IDs | 🟡 移除 |

> 完整变更清单：https://modelcontextprotocol.io/specification/2026-07-28/changelog

## 3. SDK 支持矩阵（核心事实）

| SDK | 最新版本 | LATEST 协议版本 | 支持 2026-07-28? |
|---|---|---|---|
| 官方 **Python SDK** (`mcp`) | **2.0.0**（2026-07-28 发布） | **`2026-07-28`** | ✅ **是** |
| 官方 **TypeScript SDK** (`@modelcontextprotocol/sdk`) | **1.30.0** | `2025-11-25` | ❌ **否** |
| **fastmcp** | 3.4.5（稳定）/ 4.0.0b1（beta） | 3.4.x 锁 mcp<2.0；4.0.0b1 支持 mcp 2.0 | 需 4.0.0b1 |
| **mcp-types** (Python) | 2.0.0 | — | 4.x fastmcp 新增依赖 |
| **mcp-types** (npm) | 1.0.2 | — | TS 侧未跟进 |

**关键发现**：新协议 SDK 支持是**分语言推进**的——Python 已到 2.0.0，TypeScript 仍在 1.30.0。

## 5. agora 适配评估

### 5.1 升级实验（已验证可行）

在 agora `exp/mcp2-upgrade` 分支完成 dry-run 与实机验证：

| 项 | 结果 |
|---|---|
| 依赖解析 | ✅ `uv lock` 136 包无冲突 |
| 版本升级 | mcp 1.28.0→2.0.0；fastmcp 3.4.2→4.0.0b1；新增 mcp-types 2.0.0/httpx2/httpcore2/truststore；移除 httpx-sse |
| 代码改动 | **仅 2 处 import**（`AuthContext` 从 `fastmcp.server.auth.authorization` 迁移到 `fastmcp.utilities.authorization`） |
| 全量回归 | **1474 passed / 0 failed**（差 5 个均为环境 skip） |
| ruff | 无新增错误 |

### 5.2 影响面分析

| 影响面 | 程度 | 说明 |
|---|---|---|
| 协议版本协商 | 中 | agora 无显式版本锁定，SDK 自动协商；新协议时需确认 |
| initialize 握手移除 | 中 | agora mcp_transport 依赖 initialize 流程，需迁移到 `_meta` 版本携带 |
| server/discover | 中 | agora 需实现新 RPC 以兼容新客户端 |
| transport | 低 | agora 以 stdio 为主，Streamable HTTP 变更影响小 |
| sampling/roots/tasks | 低 | agora 未使用这些特性 |

### 5.3 决策建议

**短期（现在）**：保持 mcp 1.28.0 + fastmcp 3.4.2（稳定版）。
- 主流客户端均为 2025-11-25，当前组合完全兼容
- fastmcp 4.0.0b1 是 beta，不应引入生产

**触发升级的信号**：
1. 官方 TypeScript SDK 发布 2.x（跟进 2026-07-28）
2. fastmcp 4.0.0 发布 stable
3. 新版 Claude Code / Cursor 出现 `UnsupportedProtocolVersionError`

**升级路径**（已验证）：`pyproject.toml` 改 `fastmcp==4.0.0b1` → `uv lock` → 改 2 处 `AuthContext` import → `uv run pytest tests/`。
