# Workspace ↔ Documents 联动地图

> **两侧定位**: Workspace = 治理与知识引擎（BET/门禁/搜索/决策）；Documents = 业务与知识源头（真实工作/领域知识/交付物）。
> **核心判断**: 引擎已经建完，源头刚刚接上——下一步不是建更多引擎，而是**让源头的数据流经引擎并回写价值**。

---

## 一、已有连接（本会话建立或验证的）

| 连接 | 机制 | 验证 |
|---|---|---|
| KOS 全文检索 → 全域知识 | `kos-cli search` + FTS 覆盖 29,700 条 | 15 场景全命中 ✅ |
| BET 台账 → 业务交付追踪 | T4-02~T4-06 业务单用治理通道交付 | 5 份产物 + 签发回执 ✅ |
| ADR-0460 → 业务决策 | 批量决策会 + 默认否决权 | 决策工作簿已发 ✅ |
| standards → 领域规范 | kos-home-authority.md 落地 | KOS_HOME 契约生效 ✅ |
| 治理门禁 → 文档质量 | gac-local-gate 68 checks | 审阅意见拦截空章节事故 ✅ |

## 二、缺失连接（可以做但还没建的）

| # | 连接 | 价值 | 实现 | 难度 |
|---|---|---|---|---|
| **L1** | **KOS 检索 → agent-workflow start 前置** | 每个新 BET 的 spec 起草前自动检索 KOS 找先例——知识复利启动按钮 | agent-workflow.py start 阶段加一行 KOS 查询 | ⭐ 低 |
| **L2** | **144 号纪要 5 条区级项 → BET 铸造** | 政府决议用治理通道执行（区属医院接入/AI 区级覆盖/数据质量/互联网+护理/影像平台政策） | 判定工作簿模式，铸 1-5 个区级 BET | ⭐⭐ 中 |
| **L3** | **审计督查 PDF 1,278 个 → OCR → KOS** | 卫健委域 1,278 个政策/审计 PDF 入索引后，治理知识检索覆盖率从 1,001 → 2,300+ | OCR 工具（macOS 自带 Vision.framework 或 shortdi）+ ingest | ⭐⭐ 中 |

| **L6** | **run 注册表竞态修复** | omo 子模块 lifecycle.py 原子写加固（防并发覆写 run 文件） | BET + omo 子模块提交 + 根仓 bump | ⭐⭐ 中 |
| **L7** | **公文模板库选择性检索** | 219K docx 按主题索引（如"心理健康""信息化"），写材料时按需检索 | 建独立 FTS 索引（不混入主 KOS） | ⭐⭐⭐ 高 |

## 三、建议优先级（按影响力 × 可行性排序）

### 第一梯队（本周可做，高价值低难度）

| 连接 | 理由 |
|---|---|
| **L1** KOS → start 前置 | 改动最小（一行代码），启动知识复利 |
| **L2** 纪要区级项 → BET | 把 144 号的 5 条区级项铸成 BET，用治理通道执行——业务+治理首次真正融合 |

### 第二梯队（下周，中价值中难度）

| 连接 | 理由 |
|---|---|
| **L5** 资产卡片 → 场景卡 | 5 篇方法论模型注册后，日常工作可自动触发 |
| **L6** run 竞态修复 | 原子写加固，防再次覆写 |
| **L3** PDF OCR 管道 | 1,278 篇审计文件入 KOS |

### 第三梯队（下季度，高价值高难度）

| 连接 | 理由 |
|---|---|
| **L4** 规自委深度分析 | 12 子域结构化分析是"区级视角看市级政策"的决策支持工具 |
| **L7** 公文模板选择性检索 | 219K 模板库的 FTS 索引独立于主 KOS |

## 四、联动效果预测

| 连接建立后 | 效果 |
|---|---|
| L1 | 每个 BET spec 起草时自动命中先例（知识复利启动） |
| L2 | 政府决议用治理通道执行——**治理与业务首次真正融合** |
| L3 | 卫健委审计知识检索覆盖率 1,001 → 2,300+ |
| L5 | 日常工作中自动触发方法论模型——知识从被动查到主动推 |
| L4 | "区级视角看市级政策"分析工具——**决策支持新产品** |

## 五、不建连接的理由（反模式防护）

| 不做的 | 理由 |
|---|---|
| 219K 模板全量入 KOS | 索引爆炸（16K → 235K），检索质量下降 |
| 家庭医疗 PDF 入 KOS | 隐私敏感，不属于治理知识 |
| 把 BET 系统强加给 Documents 域 | Documents 域有自己的 DOMAIN.yaml 管理体系，不应强加治理结构 |
