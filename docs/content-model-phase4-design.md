# Phase 4 约束覆盖度度量与缺口发现设计

## 目标

知道哪些内容受哪些约束保护、哪些没有。

## 设计

### 1. 覆盖度仪表盘

`bin/ssot/coverage_report.py`：
- 按内容类型 × 约束类型矩阵输出覆盖率
- 可视化矩阵（Markdown 表格 + 可选 HTML）

### 2. 僵尸约束发现

扫描无内容实例的约束：
- 声明了但无目标的约束
- 输出僵尸约束清单

### 3. 无保护内容发现

扫描无任何约束覆盖的内容类型：
- 输出缺口清单

## 实施步骤

1. 实现覆盖度仪表盘（1-2 天）
2. 实现僵尸约束发现（1 天）
3. 实现无保护内容发现（1 天）
4. 在 dashboard 中展示（0.5 天）

## 成功标准

- 约束覆盖度矩阵可视化
- 僵尸约束清单
- 无保护内容清单
