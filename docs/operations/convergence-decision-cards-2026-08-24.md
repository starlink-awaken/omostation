- 决策走 B.D.S.K 4-Corner + bet-ledger, 不强推

## 决策卡 2: metaos (编排引擎)

| 维度 | 数据 |
|------|------|
| 权威规模 | 102 py 文件 (中等) |
| Layer | L2 |
| 栈 | Python (uv, pytest) |
| 功能 | 决策门控/免疫/路由 |
| 重叠风险 | 与 omo (治理中枢) 功能语义重叠 |

**选项**:
- A. **明确边界**: 与 omo 划清 "治理执行 (omo) vs 编排决策 (metaos)", 防双轨 drift
- B. **合并进 omo**: 功能重叠面并入治理中枢
- C. **独立保持**: 保持现状但增加边界声明

**建议**: metaos 规模不小 (102 py), 不建议删除; 优先 A (边界声明 + 接口契约), 避免"两套门禁"。
**决策状态**: ⏳ 待用户/B.D.S.K
