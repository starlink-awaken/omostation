# ADR-0289: A2 type1 demote — batch5 非多 agent 真 dispatch

## Decision

1. batch5 (ThreadPool × `run_scenario`) **降级**为机制微基准，不得进入多 agent 真 dispatch 定论表，不得支撑 C 适用面「协作正收益」证明。
2. 多 agent 真 dispatch 定论表 = **3 类型** (ordered / coupled+write / independent+write)；相对验收 ≥4 **shortfall 诚实记档**。
3. C「简单独立批量」适用面 = **human D2 授权** + 类型2–4 负证据；**不**依赖 5.4x 或 batch5。

## Status

**ACCEPTED** 2026-07-29.
