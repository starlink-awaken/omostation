# ADR-0253: P84 协作模式路由 — K4 批次2「协作劣」后的路线 A

## Context

P84 K4 批次2 对照实验（#565）诚实记录：**协作 223s vs 单 agent 128s（慢 1.7×）**，
协作劣于单 agent。P84 §F 要求如实上报并请人类重估适用边界。

人类 2026-07-28 授权继续落地（会话「可以，go」），采纳建议路线 **A**：
**不撤销协作主轴，按任务类型路由模式**。

## Decision (路线 A)

1. **协作主轴保留**（ADR-0247 不动）：能力轨场景库 + 产能轨真实 backlog 双轨继续。
2. **强制模式路由**（不得一刀切全协作）:

| 任务类型 | 默认模式 | 依据 |
|---------|----------|------|
| 独立无依赖批量（doc 修复 / as_of / 场景生成 / 多文件无共享写） | **协作并行** | W1 任务#1 曾 5.4× 优 |
| 简单分析 / 串行归因 / 单线程审查 | **单 agent** | K4 批次2 1.7× 劣 |
| 有依赖链 / 冲突 / 失败注入 | **先单 agent 基线，再测协作**（批次3/4 未完成前不默认协作） | 泛化未证伪前保守 |

3. **静默丢失 = 0** 仍硬红线；协作劣于单 **必须上报**（已有 #565 先例）。
4. **批次3/4 对照实验继续**（有冲突 / 失败注入），结果再修订本表；劣则不得掩盖。

## 非决策（明确不做）

- 不因批次2 一刀切砍掉协作管线
- 不把场景数刷进产能轨
- 不为抬加速比挑理想样本只报喜

## Status

**ACCEPTED**（2026-07-28）。送卡事项关闭；执行面按路由表选模式。
