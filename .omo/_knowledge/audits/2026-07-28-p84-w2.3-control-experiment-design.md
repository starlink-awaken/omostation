# P84 W2.3 首次对照实验设计（协作管线 vs 单 agent）

> 上位: strat-p84-scenario-driven-longplan.md W2.3
> 🔴 红线 (P84 §0): **协作劣于单 agent 必须如实上报不掩盖** (掩盖负收益 = 违规)

## 实验设计
- **任务集**: 同类独立任务 (场景库 verdict 修复 / doc 修复 / 测试补齐)
- **协作管线**: N haiku 并行 dispatch (orchestrator + worker 池, 黑板协调)
- **单 agent**: 1 haiku 顺序做同任务集 (基线)
- **度量**: 墙钟耗时 / 质量落地率 / 返工率 / **静默丢失 (硬红线=0)**

## 首批数据 (W1 任务#1 DOC_CLAIMS_SCOPE, 已有实测)
| 维度 | 协作管线 (6 haiku 并行) | 单 agent 顺序估算 |
|------|----------------------|------------------|
| 耗时 | 49s (墙钟) | 267s (6×44.5) |
| 质量 | 6/6 落地, 0 返工 | 基线 |
| 静默丢失 | **0** ✅ | — |
| 加速比 | **5.4x** | 基线 |

**结论**: 协作管线显著优于单 agent (独立无依赖任务, 并行收益大).
**诚实**: 任务#1 是**理想样本** (独立无依赖). 后续须测有依赖/冲突任务验证泛化, 不能只报理想样本.

## 后续批次计划 (验证泛化)
- **批次2 (有依赖)**: C 类分解组合场景 (链式 A→B→C 依赖) — 测协作处理依赖传递
- **批次3 (有冲突)**: A 类冲突场景 (产物分歧) — 测协作冲突消解机制
- **批次4 (失败注入)**: B 类失败场景 (角色超时) — 测协作容错重分派
- 每批: 协作 vs 单 agent, **如实上报** (劣则送卡请人类重估协作路线)

## 红线 (P84 §0 + §熔断)
- 🔴 协作劣于单 agent **必须如实上报** (P84: 掩盖负收益 = 违规)
- 🔴 静默丢失 >0 **立即停管线写卡**
- 🔴 **不代批**: 实验结果上报, 协作路线重估人类拍板
- 🔴 构造场景对照实验只计**能力轨** (合规, P84 明确允许)

## 现状 (2026-07-28)
- 任务#1 (理想样本) 已有: 协作 5.4x 优于单 agent ✅
- 批次2/3/4 待跑 (W2.3 后续, 验证泛化)
- 若任一批次协作劣于单 agent → 如实上报 + 送卡 (P84 §F)
