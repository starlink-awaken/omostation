# 信息分诊心智模型 (Information Triage Mental Model)

> 状态: ACTIVE | 版本: 1.0 | 创建: 2026-07-31
> 层级: 心智模型层 (Layer 4) — 使结构显得自然的内在信念

## 核心信念

**"不是所有信息都值得同等注意力。分诊是认知效率的第一道防线。"**

## 三分类框架

```
                    ┌─────────────┐
                    │   输入信息   │
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │   分诊判断   │
                    └──────┬──────┘
                           │
            ┌──────────────┼──────────────┐
            │              │              │
     ┌──────▼──────┐ ┌────▼────┐ ┌───────▼──────┐
     │    丢弃      │ │  沉淀   │ │     提醒      │
     │  (Discard)   │ │(Archive)│ │   (Alert)     │
     └─────────────┘ └─────────┘ └──────────────┘
```

### 丢弃 (Discard)

**定义**: 不需要行动，不包含持久价值的信息。

**特征**:
- 营销/广告/促销优惠
- 社交媒体推送/动态通知
- APP 推送/续费推销
- 星座运势/物流通知

**处理**: 忽略，不入库，不提醒。

**心智模型**: "这条信息3天后还重要吗？不重要就丢弃。"

### 沉淀 (Archive)

**定义**: 包含知识价值，值得长期保存的信息。

**特征**:
- 技术文章/规范文档
- 知识教程/研究分析
- 学习资料/笔记同步
- 课程更新/读书笔记

**处理**: 入知识库，标记为可检索。

**心智模型**: "这条信息能帮我未来做得更好吗？能就沉淀。"

### 提醒 (Alert)

**定义**: 需要行动或关注的信息。

**特征**:
- 会议/截止日期
- 账单/还款提醒
- 系统告警/异常通知
- 待办/预约/审批

**处理**: 入库 + 标记需要行动 + 通知用户。

**心智模型**: "这条信息需要我做什么吗？需要就提醒。"

## 判定原则

1. **时间敏感性**: 有明确时间 → 提醒；无时间 → 沉淀或丢弃
2. **知识价值**: 包含可复用知识 → 沉淀；纯噪音 → 丢弃
3. **行动需求**: 需要用户行动 → 提醒；不需要 → 沉淀或丢弃
4. **边界 case**: 营销伪装成提醒（如"PLUS到期续费优惠"）→ 丢弃

## 实现架构

```
调用方 (aetherforge/cockpit/agora)
        │
        ▼
  triage router (Python)
        │
        ▼
  LiteLLM 网关 :4000 (OpenAI 兼容 API)
        │
   ┌────┴────┬─────────┐
   ▼         ▼         ▼
mid-local  mini-9b  deepseek-chat
(MBP JIT) (mac-mini)  (云端)
```

### 两级共识

- **Stage1**: mid-local + mini-9b 并行初筛 (~1.5s)
- **Stage2**: 分歧时调 deepseek-chat 复核 (~2.5s)
- **阈值**: 准确率 ≥80%，延迟 <2s

## 应用场景

1. **知识采集 (KOS harvest)**: 采集时自动过滤噪音，只保留有价值内容
2. **通知管理 (cockpit alerts)**: 自动分类通知，减少信息过载
3. **内容路由**: 根据分类决定内容去向（丢弃/知识库/行动列表）
4. **认知负荷管理**: 减少无关信息对注意力的消耗

## 与其他心智模型的关系

- **SSOT 原则**: 分诊结果是信息的元数据，遵循 SSOT 原则
- **债务治理**: 分诊可以识别"噪音债务"（无用信息堆积）
- **健康评分**: 信息质量影响系统健康，分诊是质量控制的第一道关
