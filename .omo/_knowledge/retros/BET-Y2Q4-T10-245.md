## 4 lessons — 固化什么

1. **ISC 的措辞必须从实测读数派生，不能从设计意图派生**。本轮两条 ISC 若照初稿交付，
   一条会在 CI/本地永远无法满足（③ 必红），一条会把预存的第二条硬失败读成本轮回归。
   **否证形状**：判据里出现「同判 / 只允许 N 条 / 应当为 0」这类**没跑过的断言词**，就先去量一次。
2. **host 字面量的绿，在 hostile HOME 下是假绿**。去 host 类改造的验收**不能**用「换环境还全绿」当判据
   —— 那正好是烧进断言的字面量的特征。正确形状是三读数：**①未声明 profile / ②声明
   `OMOSTATION_STATE_ROOT=<tmp>` 各 25 passed 同判；③`HOME=<空目录>` 只允许声明过的组合面红**，
   且红点数由一条独立断言钉成集合相等（本轮 3 / 0），否则「删掉那 3 处」也能把 ③ 洗绿。
   这条与 §7「hermetic 测试泄漏 host 状态」同源，补的是**它的反向**：泄漏面本身要被点名计数。
3. **同一次扫描产两侧，且差分目标可以不是 0**。16 → **3**（不是 16 → 0），
   并把这 3 处钉成「必须存在」。任何「收敛到 0」型判据，都要先问：**剩下的非零是不是合法**；
   是 ⇒ 反向钉住（ISC-4），否则判据奖励过度清理。
4. **同一标量行的双方重写，文本预置无解**。共享文件的**追加型**冲突可以用「插到上游未触碰位」化解
   （T10-239），**计数型**标量（`meta.total_bets`）不行。指认方式：`difflib` 对 base→main 取改动区间后，
   还要看**我这侧要改的键是否也在对方的改动区间里**。在 ⇒ 直接走 merge，别白跑一轮内容预置。
5. **pre-rebase hook 是门禁，报错里就写着授权通道**。它拒绝 rebase 时打印的是「用 merge / PR 合流」，
   不是「去找逃生口」。本轮 `SWARM_ESCAPE_ID` 一次没用，`--no-verify` / admin merge / `--force` 零发生，
   push 全程 fast-forward。
6. **写进台账的 `verify.cmd` 必须真跑一次**（`verify --execute`）。「命令看起来对」与「命令在这台机器的
   供给面上能通过」是两件事：缺 `--with pytest` 的尺**永远不会通过**，于是 packet 里的验收条款形同虚设。
   与 T10-239 第 4 条（管道吃测量）同族：**判据要在它指定的那把尺上跑通一次再落笔**。
7. **retro 必须在交付 run 的 `closeout` 之前落盘，且 `.omo/_knowledge` 不是共享桥**。
   本轮复现 T10-217 的 `missing_retro`：`chain_bind.py` 的 `retro_path_for(workspace, bet_id)` 里
   `workspace = Path(__file__).resolve().parents[2]` —— 即**执行 closeout 的那个检出**，
   而只有 `.omo/_delivery/agent-workflows/` 是 symlink 桥。所以收尾轮的 retro 要么落在交付检出，
   要么就在收尾检出里执行 closeout（本轮后者：run 记录经共享锚点可见，retro 就近落盘）。
