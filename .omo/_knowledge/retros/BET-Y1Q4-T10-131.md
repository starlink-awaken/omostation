## 实现要点

- **网络错误判定**: 10+ 关键词匹配 (SSL_connect, timeout, connection refused 等)
- **SSH→HTTPS 切换**: 检测 SSH URL → 自动转换为 HTTPS → 临时切换远端 URL → push → 恢复
- **非网络错误**: 立即失败不重试 (权限、分支保护等)
- **预检机制**: pre-push hook 中 2s 快速 SSH 检测，仅建议性输出不阻断 push
- **环境变量控制**: `GIT_RETRY_MAX` (重试次数), `GIT_NO_HTTPS_FALLBACK` (禁用切换)

## 教训

1. **BET ledger spec binding 是前置门槛**: 新 bet 需要先创建 spec 文档 + 在 ledger 中添加 `accepted_specifications` 才能 start workflow
2. **yaml.dump 不保留原始格式**: Python yaml.dump 会重排 key 顺序，对于需要精确行级修改的场景应用 read-line → modify → write-line 策略
3. **pre-push hook 设计原则**: 预检应该 advisory (exit 0) 而非 blocking，让 git-retry 在实际 push 时处理重试
