## 4 lessons

1. **V3 向后兼容优先**: V4 在 v3 基础上扩展, 5 axis + A2 KV cache 全部保留. test_compute_axes_backward_compat 守护旧 contract.
2. **realtime 必须用 `today_start_utc()` 而非 `_utc_now() - 1d`**: 跨日时区一致性.
3. **D2 杠杆率 0/0 fallback**: A=0 时 (无 A 类事件) 不能除零, 用 0 + score=50 (neutral) 占位.
4. **报告写入 atomic file lock**: 多次运行同日期必须幂等, 覆盖而非新增. 用 `fcntl.flock` 保证并发安全.
