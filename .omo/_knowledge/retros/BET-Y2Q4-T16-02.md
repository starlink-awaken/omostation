# BET-Y2Q4-T16-02 Retro — 日志面分类 SSOT 轮转资格登记驱动与防清零闭环

## 交付概要

| 项 | 交付与证据 |
|---|---|
| 日志面分类注册表建立 | 建立 `.omo/_truth/registry/log-surfaces.yaml`（`schema: log-surfaces/v1`），定义三类互斥词表（`log` / `state` / `projection`），实现可轮转资格登记驱动而非文件名枚举 |
| 4 大核心证据账本硬性保护 | 将 `agent-workflows/events.jsonl`、`resident-orchestrator/receipts.jsonl`、`ingress/value-evidence.jsonl`（BET 价值证据）、`observability/events.jsonl` 登记为 `class: state`，硬性禁止轮转 |
| 防御性登记去重水位 | 将 `event-ingest/watermark.json`、`perception-inbox/watermark.json`、`personal-signals/watermark.json` 显式登记为 `class: state`，防止日后 pattern 扩充导致去重失效 |
| 消费端与可观测性 | `bin/ssot/log-rotate.py` 消费注册表；`--dry-run` 显式输出 `exclude(state)` 排除项、`unclassified` 未分类候选，消除旧 `SKIP_NAMES` 静默拦截 |
| 覆盖面缺口修复 | 将历史漏扫的 4 个日志目录（`event-ingest`, `perception-inbox`, `personal-signals`, `agent-workflows` 直属日志）登记为 `class: log` 并纳入扫描面 |
| 单文档 YAML 契约修复 | 去除注册表中冗余的第二道 `---`，保证标准 `yaml.safe_load()` 验收命令与 `yaml.safe_load_all()` 均可无错解析 |
| 自动化回归测试 | `tests/unit/test_log_rotate_copytruncate.py` 与 `test_log_rotate_state_exclusion.py` 10 项测试 100% PASS |

## 关键收益与架构对齐

1. **根除证据链静默清零风险**：`--daily` 语义为「跨天即轮转不看阈值」（每天 03:00 执行），过去靠硬编码文件名 `SKIP_NAMES`，漏判即导致追加式账本被 `os.truncate` 清零且无告警。本单转为路径级 SSOT，从根本上锁死证据丢失路径。
2. **渐进式影子阶段防线**：依照 ADR-0458 与 ADR-0457 规范维持在 shadow 阶段，`log-rotate` 报告未分类路径但不阻断日常轮转或提交，避免历史存量未分类导致门禁死锁。
3. **软链真路径防穿透**：`_load_log_surfaces` 同时存储原始路径与 `target.resolve()` 路径，彻底解决工作区为软链或挂载点时由于路径字符串不匹配而导致 state 排除静默失效的缺陷。
