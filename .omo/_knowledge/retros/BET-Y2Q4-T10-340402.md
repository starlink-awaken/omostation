## Q5 下一个认领本 track 的 agent 需要知道什么？
1. **边界**：这是生产兼容参考实现，不是生产 Authority 或记忆系统接管；不要把 delivery acceptance 混同为生产 rollout。
2. **HMAC**：测试只用显式公开 fixture；生产接入前必须先做密钥分发、轮换、最小权限和审计治理，不得复用 secret。
3. **迁移与恢复**：生产启用需要设计 schema 迁移、既有 lease 数据兼容策略、备份恢复演练和 stale epoch 处理。
4. **监控**：上线前要为 acquisition conflict、fencing violation、HMAC failure、tombstone replay 和 attempted revival 建立指标与告警。
5. **账本**：operational 与 value 维持 `NOT_PROVEN`；生产采用必须另立 evidence 计划，不要借本 BET 补证据。
