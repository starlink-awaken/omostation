invoke old Documents writers even after their primary schedules had been
replaced. Moving the watcher implementation to Workspace closes that bypass.

to a Documents writer. A future Workspace verdict owner can be registered and
added without restoring Documents execution. The minute cron was replaced
under run `20260827T200025Z-governance-state-mutation-6575ec3b` using
accepted-20260903; the old line is zero, the new line is one, and 108 unrelated
lines are byte-identical. Post-smoke returned a clean JSON envelope with no
events on stable inputs.
