removed from the Documents execution plane and moved to a Workspace quarantine.
No permanent deletion occurred. The manifest is complete and reversible.

## Q2. Evidence status

- Engineering: exact target list, byte counts, modes, and source/target SHA-256
  values are recorded in the quarantine manifest and repository report.
- Operational: preflight had no open handles or active executable consumers;
  postflight confirmed all eight sources absent, target hashes equal, and the
  remaining `_inbox` scoped L4 audit returned content-only `ok=true`.
- Governance: consumer audit stayed `0 forbidden_executors` and `0 unmatched`;
  the physical registry status remains a separate follow-up write.
- Value: not evaluated; this is a boundary and hygiene delivery.

## Q3. What went wrong and what changed?

The first transaction implementation treated expected parent-directory metadata
changes as non-target mutations, then had two small staging/parent-path bugs.
Every failure rolled back and source hashes were rechecked. The final design
uses split parent-scoped transactions, ignores only expected parent metadata,
compares non-target regular files, and keeps an explicit rollback manifest.
