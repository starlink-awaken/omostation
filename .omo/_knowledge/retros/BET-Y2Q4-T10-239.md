## 4 lessons — 固化什么

1. **「采纳上游字节」≠「冲突消失」**。共享文件的尾插冲突，判据是两侧**改动区间是否重叠**以及
   **新增内容是否与对方同文**，不是「我的底稿等于上游」。同文尾部会让 xdiff 错对齐。
   指认方式：`difflib.SequenceMatcher` 对 base→main 取 opcodes，插入位与任何改动区间留出**几十行**余量。
2. **`git merge-tree --write-tree` 是 push 前唯一的非破坏性冲突探针**，它评 commit 不评工作树，
   所以必须提交后再探。GitHub 侧 `mergeable=CONFLICTING` 的 PR **根本不排队** ——
   `gh pr checks` 零输出不是放行（本 BET 实测：解冲突后 `mergeable=MERGEABLE`，31 条检查全部开始跑）。
3. **摘库后的生成态是本地/CI 的不对称面**。`.omo/state/system.yaml` 在 `origin/main` 已不被跟踪
   （BET-Y2Q4-T10-235），CI 由 `gac-gate.yml:143` 与 `state-goals-enforce.yml:30` 各自的
   `materialize-system-state.py` step 先物化，本地 worktree 没有 ⇒ `current-state-coherence` rc=2
   `missing input`。判据顺序：先 `git ls-tree origin/main -- <path>` 确认它是否还在跟踪面，
   再跑创建者物化（`key_set_equals_declared=true`）⇒ 该条 rc=0。别把「本地少一个生成文件」读成写面回归。
4. **管道与别名继续吃测量**：`| tail` 把 rc=2 报成 0；`/usr/bin/cat` 在本机不存在（rc 127 静默截断
   整条复合命令，后续测量全丢）；zsh 里 `grep`→`rg`，`grep -E` 报 `unknown encoding`。
   凡判据读数一律重定向到文件后单独取 rc，且判据文本写清用哪把尺（`[[:space:]]` 替 `\s` ——
   `git grep -E` 的引擎不认 `\s`，同一条判据换装置读数不同）。
5. **登记缺口优先于绕过**。`check-work-landed` 被 `gac-local-gate.py:251` 的 `"timeout": 45`
   在负载下杀掉，而该 cap 未登记 `gate-known-debt.yaml` ⇒ 记为独立一轮，不放宽 cap、不改判据。
6. **WorkPacket 只认 start 时的投影，不认你后来的好意**。`scope.write_surfaces` 在 claim 时从活台账
   重导并比 packet hash（`bin/plan/bet-ledger.py:2333-2337`），所以「声明面」这件事本身需要一次
   bet-bound run 先落地，之后才能有一个 packet 含它们的 run 去写。顺序：**台账定稿 → start → claim 完 → 才改投影字段**。
   反面形状是「先改台账再 claim」，它不是失败而是 `WORK_PACKET_SOURCE_DRIFT`，且新建 BET 首轮用不上
   `refresh-packet`（`bin/agent-workflow.py:1031` 要求 ledger+spec 已在 `origin/main` 逐字节相等）。
7. **证据指向的树必须含它担保的改动**（T10-238 retro 第 9 条在本轮复现的形式）：
   `merged_reachable_commit` 只校验对象可达（`bet-ledger.py:1682`），所以指错一个「更早但可达」的
   commit 永远绿。本轮把它钉在 `a682300fa` —— 用 `git show a682300fa --name-only` 核对它确实含
   台账条目、spec、`verify-omo.sh` 文件表与新 step，而不是只看 rc。
8. **依赖面 ≠ 回归**：同一把尺换 venv 供给方式就从 35 绿变 3 红。先跑「兄弟包在不在」再定性红因，
   不为了绿而摘用例。
