# BET-Y1Q3-T10-112 Closeout Retro

> **TL;DR**: V1 OA adapter + 10/10 单元测试 PASS. OA 系统是 web-based (HTML), 非 REST API. 当前使用 mock 数据, 待 human operator 提供 API 文档后替换为真实接入.

## 5 lessons

1. **Web-based OA ≠ REST API**: 致远 OA (http://10.216.16.151/) 返回 HTML 页面, 不是 REST API. 需要 session-based 认证 + 页面解析, 或等待官方 API 文档.
2. **Mock-first 策略**: 在真实 API 不可用时, 先写 mock data + adapter interface, 后续替换为真实实现. 10/10 测试覆盖核心逻辑.
3. **@sandbox decorator 模式**: 与 T2-01/T10-119/T10-121 一致, 装饰器 + functools.wraps 保留元数据, `_sandbox_level` / `_sandbox_protected` 属性供 introspection.
4. **circuit_breaker 5ms 阈值**: 实际 OA HTTP 请求 >5ms, 触发降级. 这是预期行为 — 投机解码命中率 <40% 时降级为自回归.
5. **exec-based test loader 是 py3.14 的 V1 标准**: 之前多个 BET 都用, 这次 T10-112 继续. `types.ModuleType + exec(compile(src, path, "exec"), mod.__dict__)`.
