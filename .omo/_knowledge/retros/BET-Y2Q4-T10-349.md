# Retro — BET-Y2Q4-T10-349

## 1. 意图（intended）

`bin/mof/gen-service-configs.py --check` 自 2026-11-10 起对本机永久假红，阻塞一切
本机 gac-local-gate 全绿与 workflow closeout（含同日伴生 BET-Y2Q4-T10-348 的
closeout 链）。本 BET 消除该假红并把 11-10 手工修复回填 SSOT。

## 2. 实况（happened）

**两层根因（第一层初判有误，已修正）**：
- 对比层：check 对本机 plist 与 services.yaml 现场生成版做逐文本对比 —— 11-10
  模板手工补解释器 NOTE 并整份覆盖本机（LAUNCHD-PLIST-INSTALLED-DIVERGED 的
  正确处置）后，注释/紧凑排版差异被误报为 drift。
- 声明层：11-10 手工修复新增的 WorkingDirectory / EnvironmentVariables(PATH+
  no_proxy) / StartCalendarInterval(:05/:35) 未回填 services.yaml，生成器也不
  支持渲染 —— 真漂移。**初判"仅剩 <!-- / --> 定界符差异"系自写过滤脚本的
  口径错误（XML 注释行被当缩进滤掉），按 §6.6 精神在台账/spec 公开修正。**

**验证数字**：test_gen_service_configs.py 20 passed（新增 4 用例：注释忽略/
排版等价/实质漂移仍报/新字段渲染）；修复后本机 `--check` **0 drift (78 launchd
services)**，11-10 以来首次全绿；T348 的 verify 6/6 PASS（含 gac-local-gate）。

**中途波折**：统一渲染 array 曾让 morning-brief / spine-daily-ingress 报新假
drift（plistlib 下 dict ≠ [dict]，尽管 launchd 运行时等价）—— 单 dict 声明
保持单 dict 渲染后归零。"语义等价"必须含类型形态，不能只看内容。

## 4. 教训（lessons）

- 机器级配置（~/Library/LaunchAgents）锚定 canonical 检出是 2026-08-08 事故的
  教训 —— worktree 里跑 --check 读主仓声明属设计行为；"worktree 修复 + 主仓
  镜像声明副本 + PR 合并收敛"是正解，不是绕过。
- 排障过滤脚本本身就是 bug 源：过滤条件想当然（# 当注释、空格当缩进）会造出
  "纯注释差异"的假结论。定性前用解析器（plistlib/plist)而不是手写正则。
- change-lane-check 拦住混合 lane 提交是对的 —— 治理状态/治理代码/测试分开
  留痕，revert 粒度才干净。
