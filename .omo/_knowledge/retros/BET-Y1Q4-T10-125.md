# Retro: BET-Y1Q4-T10-125 — Resident BOS 双向任务网关与异步队列调度中枢

## Summary

常驻 agent 体系扩展：BOS 双向任务网关 + 持久化任务队列 + daemon tick 派发循环。

## What went well

- **分层 PR 策略**：3 个子仓库分别合并 (omo#155 内核 / omo#156 daemon / agora#75 BOS), 主仓只做 ledger closeout
- **测试覆盖**: 20 unit tests × 0.5s (状态机/容量/重试/并发/持久化全场景)
- **CI 全绿**: lint + test + test-cov + check-resident-bos.py 全部 PASS
- **架构决策**: SQLite WAL + `BEGIN IMMEDIATE` 实现多 daemon 派发原子性, 无需引入 Redis

## What was learned

- **`isolation_level=None` + `BEGIN IMMEDIATE`** 是 SQLite Python 写锁的标准范式
- **状态转换合法性表 `_ALLOWED`** 把"严格单向状态机"从注释升级为代码可执行约束
- **`status_override` + `attempts_override`** 解决"事务内 UPDATE 后返回旧 row"问题
- **`git checkout -- file`** 在 submodule 中会丢未提交改动, 重置前必须先备份

## What to improve

- daemon hook 只注册了 2 个 URI (sediment/decision trigger), 真实 sediment/decision 落盘逻辑需扩展
- task_queue 暂不支持优先级队列 (FIFO only)
- retry 当前立即重试, 真实场景应加 exponential backoff
