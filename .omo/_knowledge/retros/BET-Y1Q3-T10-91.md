# BET-Y1Q3-T10-91 retrospective

## Q1. What was intended?

Restore valid completion-evidence references after the maturity scorecard file
changed in later governed work.

## Q2. What happened?

The eight references to the old scorecard digest were replaced with the
current file digest. The two affected matrices now validate without changing
their historical status or attestation semantics.

## Q3. What was discovered?

Completion evidence is content-addressed, so a legitimate later file change
can invalidate historical matrices even when the original work remains valid.
The derived overall-state errors were consequences of the digest failures,
not new delivery failures.

## Q4. Surface accounting

Net repository change is limited to eight ledger digest scalars plus the
governed spec, report, retro, and bootstrap waiver. No implementation,
Documents, client-state, runtime-payload, or evidence-file bytes changed.

## Q5. What should the next agent know?

Run `bet-ledger lint` after any evidence-file change and update references in a
separate governed slice. Do not silently replace the referenced evidence file
to make an old digest pass.
