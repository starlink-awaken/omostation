# BET-Y1Q3-T10-37 retro

The Scheduled skill was an operational consumer even though it looked like
human instructions: it directly named Documents executables and their history
outputs. Replacing those steps with accepted Workspace evidence removes the
execution ambiguity while preserving the weekly/biweekly review intent.

The workflow runner currently rejects absolute external paths during claim, so
the target was backed up via an exact inverse transformation and its before /
after hashes were recorded. This limitation should be addressed in the
workflow's external mutation surface model before more Scheduled files are
migrated.
