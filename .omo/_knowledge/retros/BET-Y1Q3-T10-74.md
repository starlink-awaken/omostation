# BET-Y1Q3-T10-74 retrospective

## Q1. What was intended?

Reconcile five OMLXC BOS script declarations and update the Workspace root
gitlink to the merged Agora child without changing service behavior.

## Q2. What happened?

Agora PR #46 merged the three stale `bin/demo` references to the canonical
`examples/live_nextgen_compute_engine_benchmark.py` path. The dma/lora
declarations already referenced the canonical V5 example. Root integration
exposed a second issue: evidence-smoke ignored `--directory` when checking a
direct script, so a narrowly scoped T10-75 checker fix was integrated.

## Q3. What was discovered?

The command's relative path is resolved from the directory selected by `uv
--directory`; converting it to a Workspace-root path makes the actual command
fail. Declaration correctness and checker correctness are separate contracts.

## Q4. Surface accounting

The root surface contains one child gitlink update, the checker/test
integration, one ledger/spec/waiver set, one report, and one retro. No new BOS
URI, dispatcher, registry, runtime payload, Documents content, or hardware
execution was added.

## Q5. What should the next agent know?

Re-run the full root evidence gate only after all required submodules are
initialized. Keep the T10-71 missing Spec and task-count/resident-BOS baseline
separate from this OMLXC path fix; do not hide them in a path declaration.
