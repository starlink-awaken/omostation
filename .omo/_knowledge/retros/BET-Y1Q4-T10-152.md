# BET-Y1Q4-T10-152 retro — A5 残留死引用修复（ws-t1069 → Workspace）

## What changed

- 三个 launchd 服务 `com.omostation.resident-daemon` /
  `com.omostation.pipeline-morning` /
  `com.omostation.tailscale-heartbeat` 的 plist（`~/Library/LaunchAgents/`，
  不在本仓库内）里所有 `/Users/xiamingxing/ws-t1069` 替换为
  `/Users/xiamingxing/Workspace`，无其他改动。
- 认领前先查了 `gh pr list --search "ws-t1069 OR resident-daemon OR
  pipeline-morning OR tailscale-heartbeat"`，确认没有其他 PR/agent
  在处理这三个服务的路径问题，符合本 BET non_goals 的前置要求。
- 操作前先 `cp` 备份三个原始 plist；`launchctl unload` → `sed` 替换
  → `plutil -lint` 校验合法 XML → `launchctl load` → `launchctl
  kickstart -k` 强制触发验证。
