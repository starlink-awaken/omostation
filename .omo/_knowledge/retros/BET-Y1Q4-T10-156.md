# Retro: BET-Y1Q4-T10-156 (Diff Growth Detection)

## Summary

计算当前分支相对 base 分支的代码增长量, 超过阈值时标记 warning, 防止单 PR 代码膨胀。

## What went well

- 用 `git diff --shortstat base..HEAD` 一行计算 +/- 行数, 不需要 patch 文件
- 与 check-bin-quota-diff 互补: 后者按脚本数 (count), 前者按代码行数 (LOC)
- thresholds 可配 (warning=500, blocking=2000), 留给 CI 调优空间

## What was learned

- 包括空行/注释/doc 的 +/- 计数偏宽松, 可加 `--stat-with-options=--shortstat` 区分
- "代码膨胀" 的真正常见模式: 大型 refactor (2000+ 行删除) + 大量新增 test, 净增 0 但仍触发 warning

## What to improve

- 支持 per-track 阈值 (T7-SCENE 容忍 1000 行, T10-MATURITY 容忍 200 行)
- 与 LLM-based diff summarizer 联动, 自动生成 "为什么这次代码膨胀" 的 brief

## Metrics

- Files: 1 script (203 LOC) + 1 test (107 LOC)
- 覆盖: 5 种阈值边界
- Appetite used: 0.5d (within 1 sprint)
