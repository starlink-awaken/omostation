## Q3 过程中发现的与 plan 不符的事实（打假）

1. **`work_packet_hash` 会在重编号后静默过期**：重编号改了 run 的 `work_packet` 内容（bet_id 208→209）
   却没人重算 declared hash → claim 报 `WORK_PACKET_HASH_MISMATCH`。实测 packet 内容与
   `prepare_bet_execution` 重投影**逐字节一致**（measured == rebuilt），所以错的是 declared 这一侧。
   plan 完全没提"改 packet 必须重算 hash"这条维护义务。
2. **start 时的 `write_surfaces` 不含 closeout 产物** → claim retro/receipt 报 `WORK_PACKET_SCOPE_MISMATCH`。
   T10-207 先例的 surfaces 明确含 receipt + retro 两面；我方 start 只带了 10 个交付面。
   收尾产物是每个 bet 的必经终点，**不该等收尾时才发现面清单少了它们**。
3. **claim 还有第三闸 `affected-hash`**（错误文案只说"run affected-graph.py first"，不给命令）。
   真实用法要从历史 retro（T6-14 / T8-02）里挖：
   `bin/gac/affected-graph.py --changed-projects omo workspace-root --output .omo/_delivery/affected-graph/<id>.json`
   再 `claim --affected-hash <receipt>`；文档路径映射到 `workspace-root` 必须带上。
4. **台账里存在零语义重复键**：`BET-Y2Q4-T10-04` 条目 `completion_evidence`、`value_indicator_policy`
   各出现两次（两套完整 block）。PyYAML last-wins 让 lint 一直绿（495 OK），strict parser 却会直接炸。
   `origin/main` 同在 —— 既有债，非本波引入。处置：删 first 死块，断言
   `yaml.safe_load(before) == yaml.safe_load(after)` 全等后落盘。
5. **LSP 的重复键报错行号不可信**：报的两行实际是 list item 不是 map key；必须用
   `yaml.compose` 递归检测定位真实重复，不能按 LSP 行号直接改。
6. （第一波已证，本波复述）`gac-worktree.sh merge` 在 gh squash **之后**才 `checkout main`，
   共享主区脏树时 fatal → 合并已成功但释放段没跑；gate 必须 commit 后跑，staged 中间态会
   write-owner-audit / change-lane-check 双假 FAIL。

## Q4 下次可复用的做法（固化）

- **声明与重投影永远成对**：改 `work_packet` 或 ledger `write_surfaces` 后，立刻
  `prepare_bet_execution` 重投影并同写 `work_packet` + `work_packet_hash` 两键；只改一个是必炸的半步。
- **start 的 surfaces 带上收尾面**：`.omo/_knowledge/retros/<BET-ID>.md` 与
  `docs/reports/<date>-<slug>-closeout.md` 应进每个 bet 的初始 `write_surfaces`（T10-207 / 本条先例）。
- **claim 三闸按报错逐个解，不盲目重试**：hash（重算）→ scope（扩面+重投影）→ affected-hash
  （跑 graph receipt）。三个错误码互不重叠，一次只修一闸。
- **gate/tree 等价引用法**：`git rev-parse <merge>^{tree}` == `<head>^{tree}` 时，一次
  "commit 后 gate PASS"即可覆盖合并树，不必在每个波次重跑全量门禁。
- **台账文本级编辑三件套**：① 文本锚点插入/删除保格式（禁 yaml.dump 回写全文件）
  ② `safe_load` 前后语义全等断言 ③ `compose` 递归 dup-key 检测 —— 三步都过才落盘。
