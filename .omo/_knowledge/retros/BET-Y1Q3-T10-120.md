## Lessons

1. **drill 设计应尽量本地化**:** 任何 chaos 注入都应在 `tempfile.TemporaryDirectory` 内
   完成, fixture 用 `with` 自动清理, 不留任何 `.tmp/chaos-*` 残留
2. **submodule drill 需 `--initial-branch=main`**: 新 git 默认 `master` 与
   父默认 `main` 不一致会导致 `git submodule add` 失败
3. **git status --porcelain 折叠目录**: `?? bin/injected.py` 折叠为 `?? bin/`,
   检查时用文件名 substring 而非精确路径
4. **`is_throttled` 是 read-only property**: 基于 `thermal_pressure`, 不应直接赋值
5. **mass-deletion 检测必须先 git add**: `git add -A` 后 status 不再显示 deleted,
   检测必须 `git rm` 之前进行
