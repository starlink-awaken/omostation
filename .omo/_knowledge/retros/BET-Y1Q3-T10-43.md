# BET-Y1Q3-T10-43 implementation retro

## Outcome

Five OMO governor/verifier/replay/alert/status records were registered as
lifecycle-only launchd observations but had no machine plist contract. They are
now explicitly `generate: false`, so the plist generator neither writes nor
compares a fictitious host service for them.

The generator now validates every generated launchd declaration before rendering
it. Missing label, interpreter, or entrypoint is a deterministic validation
violation rather than an unhandled `KeyError` in `--check`.

## Evidence

- RED: focused validator tests failed because `validate_service_declaration`
  did not exist.
- GREEN: `tests/test_gen_service_configs.py` passes with lifecycle-only and
  missing generated-launchd-field coverage.
- `--validate --json` passes for the repaired registry.
- `--check --json` now reports 14 pre-existing host plist drifts structurally;
  it does not write plist files or raise `KeyError`.

## Residual

The 14 reported host drifts are outside this BET. They require a separate
host-config reconciliation with explicit plist ownership and rollback evidence.
