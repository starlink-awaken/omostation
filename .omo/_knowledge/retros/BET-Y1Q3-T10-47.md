# BET-Y1Q3-T10-47 retro

The mainline GaC gate exposed a deterministic environment seam: the installed
Homebrew-generated plist files use `/opt/homebrew/bin/python3`, while the
generator under `uv run` scanned PATH after excluding uv paths and selected
`/usr/bin/python3`. This BET isolates the repair to stable interpreter
selection; it does not rewrite host plist files or change service semantics.
