# BET-Y1Q3-T10-109 retrospective

## Q1. What was intended?

Close the L4 blind spot that treated machine-generated logs as human content,
without globally classifying `.log`, bypassing content archives, or mutating
Documents. Detection had to reach child main, root main, and a real read-only
canary before any physical cleanup BET began.

## Q2. What happened?

The work decomposed correctly into design/bootstrap, L4 child implementation,
root pointer, and terminal evidence. Tests observed RED before production edits.
The child PR merged as `97a3b34b92744c0efee8a1fa8b8b7c4716646e39`;
the root pointer PR merged as
`b267b2b65ab9b280702fe069c77241800036f986`. Required child and root checks
passed, and root-main replay classified both real runner logs with no metadata
change.

## Q3. What changed in the design?

The semantic rule did not change. Two evidence-ordering refinements improved
delivery:

1. a test was isolated below `tmp_path/domain` after the existing autouse
   `l4_domain_paths.toml` fixture was proven to add unrelated content at the
   fixture root;
2. terminal report, retro, and `done` transition moved to a separate closeout
   PR so they can cite the already merged root implementation SHA.

The separate closeout is not ceremony: it prevents a branch-only pointer from
being represented as mainline completion.

## Q4. What was the surface accounting?

Child production added one private helper and two decision-tree branches. Child
tests added selected-context, preservation, archive-precedence, safe-symlink,
and CLI-envelope coverage. Root surfaces added one specification, one detailed
plan, one report, one retro, one BET record, one waiver, and one gitlink advance.
No new CLI, registry, artifact kind, issue code, dispatcher, or control plane was
created.

## Q5. What remains?

T10-110 must separately preflight and reversibly quarantine the two zero-byte
runner logs after rechecking open handles, consumers, path identity, metadata,
target durability, rollback, and non-target Documents stability. It must not
reuse T10-109's read-only proof as movement authorization.

The stable full-tree audit remains non-green from large pending migration
families and archive-contract drift. Historical `public-runtime` and
`root-oneoff-assets` rollback gaps also remain open and must not be falsely
closed by this classifier change.

## Q6. What value is proven?

Engineering and live classifier behavior are proven. Physical cleanup and
principal-bound user value are not. The practical gain is stronger truth:
machine logs can no longer hide as ordinary content, enabling T10-110 to be
verified by the canonical gate rather than by an ad hoc path list alone.
