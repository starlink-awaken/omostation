## Changed / Lessons

- Installing an asset is not deploying behavior: for a long-lived server the
  operational axis can only reach `PROVEN` after the authorized restart canary;
  the closeout must state `DEGRADED` honestly rather than claim the fix is live.
- The v1/v2 display divergence (`29` vs `30` remaining) is a projection-truth
  bug class: readiness counts must bind to the same validation path as the
  canonical Panorama v2 counter.
