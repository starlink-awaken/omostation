# BET-Y1Q3-T10-114 Closeout Retro

> **TL;DR**: V1 集成 DFlash 2 块扩散 + circuit_breaker, 9/9 单元测试 PASS. 真机 benchmark 留给 future (需 MBP M5 Max + Mac mini M4 双机环境). V1 已为后续真机部署准备完整 API + 验证函数.

## 5 lessons

1. **V1 集成模式复用**: 与 T2-01 一致 — 现有 V1 API 增字段 + 验证函数, 不重写 V1. 9 个测试覆盖常量/决策/cb/throughput/speedup/router.
2. **frozen=True 字段顺序**: dataclass 字段顺序敏感 — `dflash2_enabled` 和 `draft_hit_rate` 必须放在 `target_tier/recommended_model/draft_model/estimated_speedup_ratio/reasoning` 之后 (有默认值的字段放最后).
3. **circuit_breaker 阈值选择**: `should_fallback_to_ar(0.40) = False` (≥ threshold 不降级). 严格 > 比较, 与 event_bus 的 `depth > ALARM_THRESHOLD` 一致.
4. **target_tier 字符串扩展**: V1 的 `local/cloud/hybrid-speculative` 之外增加 `dflash2` 选项. 但 V1 router 当前 3 个分支都启用了 dflash2, 未来按 prompt 复杂度区分.
5. **真机 benchmark 必须独立**: V1 测试模拟 hit_rate. 真机需 MBP M5 Max (128GB) + Mac mini M4 (24GB) 双机环境, 1-2 周累积数据才能有有意义的 120 tokens/s 读数. V1 spec 已含 `dflash2_throughput_target_met` / `dflash2_speedup_target_met` 验证函数, 真机部署时直接调用.
