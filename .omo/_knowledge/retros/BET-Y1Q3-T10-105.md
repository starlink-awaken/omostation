## 踩了什么坑

| 踩坑现场 | 根本原因 | 优雅修复方案 |
|---|---|---|
| `ReplaySample` 反序列化导致 `stats()` 返回 0 域 | `value-evolution-connector` 写入了 `task_id` 扩展字段，而 `ReplaySample` 原定义未包含该字段，`_restore` 中的 `ReplaySample(**data)` 触发 TypeError 并被静默吞掉 | 1. 在 `ReplaySample` 中补充 `task_id: str = ""` 字段；2. 在 `_restore` 中增加 forward/backward 兼容的白名单字段过滤，彻底杜绝静默失败 |
| 中文文本 ROUGE-L 评估 baseline 得分为 0.0 | `_rouge_l_f1` 原实现直接使用 Python `.split()` 按空格分词，未分词的整句中文无法与目标匹配，LCS 长度为 0 | 实现双语正则词元切分器 `_tokenize_text`，对中文字符做单字切分并保留英文与数字词汇，实测对齐评估提升从 0% 恢复至真实提升率 |
| `cmd_spine_distill` 未传 router 报 `needs_mlx` | 原 CLI 实现调用内部 python snippet 时未构造 Mesh Router 实例，当本机未装 `mlx_lm` 时无法触发网格漫游 | 在派发脚本中自动注入 `RoamingComputeRouter` 与对等发现节点 `node-macmini-m4`，优雅实现向 M4 的弹性漫游派发 |
