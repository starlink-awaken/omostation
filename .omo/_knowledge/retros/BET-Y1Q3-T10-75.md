# BET-Y1Q3-T10-75 retrospective

## Q1. What was intended?

Make the evidence checker and the actual `uv --directory` command contract use
the same relative-script path semantics, removing false script-not-found gaps.

## Q2. What happened?

The old checker always rooted direct scripts at Workspace. A minimal RED test
reproduced the mismatch. The smallest fix joins relative scripts to the
declared directory and preserves root-relative behavior when no directory is
declared.

## Q3. What was discovered?

Changing service declarations to root-relative paths would make the checker
green but make the actual `uv --directory` command fail. The correct owner of
the semantic correction is the checker. The five OMLXC declarations resolve
when evaluated against Agora main `61af943`; the root gitlink still needs its
separate integration delivery.

## Q4. Surface accounting

One checker branch, one focused test file, one specification, one report, one
retro, and one BET ledger entry were changed. No BOS URI, service command,
Documents file, runtime state, generated state, or hardware execution changed.

## Q5. What should the next agent know?

Land this fix with the T10-74 Agora gitlink update before declaring the root
evidence gate clean. Re-run the full evidence gate after all required root and
submodule surfaces are present; do not use the focused resolver test alone as
proof of mainline closure.
