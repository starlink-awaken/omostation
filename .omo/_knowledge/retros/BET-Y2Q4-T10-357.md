## 3. 坑（坑记档, 供后续 BET 避让）

1. **work 包投影绑定是 start 时刻快照** —— 台账 write_surfaces 后改路径
   (共享库 bin/lib → lib 挪窝), claim 即 WORK_PACKET_SCOPE_MISMATCH → 修
   台账后又 WORK_PACKET_SOURCE_DRIFT (packet_hash 对不上)。绑定后改写面
   = 治理链死锁, 唯一解是 close 掉 run 重开。
2. **closeout --status failed 是终态, 且连锁比想象多** —— 触发 BET closed
   标记 + root-gate/bet 双锁残留 (heartbeat 服务还会重建锁); 手工改 run
   文件 status/closed-at 复活无效 (事件流终态为准)。正路: `close <run>
   --status ... --evidence` (pitfalls.md 已有判据「run 一旦关闭即终态」),
   再 rm 陈锁 + start 新 run。
3. **共享库归属要看消费者注入路径** —— 生成器 sys.path 注入的是根 lib/
   (capability_native_sources 所在), install-cron-plane 注入的是 bin/lib/
   (cron_normalize 所在)。放错家 = 双方都要改注入。最终归位 bin/lib (cron
   基础设施同居), 生成器薄壳处加第二注入。
4. **探针脚本的 worktree 环境依赖清单** —— uv 在 ~/.local/bin (PATH 补位);
   run_cmd 解释器须带 pyyaml (cron 链 .venv/bin/python3 有, 裸 python3.13
   无); worktree cockpit 无 .venv (uv run 现场建, 缓存命中可接受)。
