# BET-Y2Q4-T10-340401 retro

Ledger: `docs/plans/3y-bet-ledger.yaml`  
Specification: `docs/superpowers/specs/2026-10-20-v34-canonical-scene-parser.md`

## What changed

The implementation converged scene-card parsing in review, lifecycle, and lineage on one read-only parser. The final round also restored the required write-back rule: when an existing frontmatter mirror has the same constrained value as the body, promotion or transition updates both values in memory, re-parses the serialized result, and only then replaces the file. It does not create a new mirror.

## Useful incident

When the new caller tests were run in a larger focused suite, two pre-existing aggregate-gate tests failed even though their fixture cards were valid. The product parser was correct. The caller test had registered the lifecycle script under the generic module name `test_lifecycle_parser`; that entry remained in `sys.modules`, so the later lifecycle-check module loaded a different script object under the same key and observed stale behavior.

Changing the test-local module names to collision-safe names restored all 45 focused tests. The failure was valuable because it proved the suite can expose cross-test pollution instead of quietly hiding a caller divergence.

## Verification discipline

The first full local gate failed on missing checkout inputs, not on the change: absent `projects/agora`, absent `projects/runtime`, missing `cockpit-ui/dist`, missing materialized state, and an incomplete evidence-smoke report. After initializing pinned submodules and generating those local validation artifacts, file-scope and workflow-scope gates passed. The receipt records that distinction rather than reporting the first red run as the final result.

## Boundary

The shared parser now rejects ambiguous and malformed YAML before business validation. This does not confer admission, prove production readiness, or establish user value. Real scene-card repair, projection refresh, and deployment remain separate decisions.
