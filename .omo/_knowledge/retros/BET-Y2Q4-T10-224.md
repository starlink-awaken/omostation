# BET-Y2Q4-T10-224 retro

receipt：`docs/reports/2026-10-04-bet-224-launchd-reality-derived-root-closeout.md`
契约：`docs/superpowers/specs/2026-10-04-bet-224-launchd-reality-and-derived-root-assertions.md`

## 1. 本意要发生什么

B4b 批次 2 要把 43 个 plist / 40 条 cron 的根从 `~/Workspace` 改道。改道前需要两样东西：
一份可信的 launchd 现实登记，和一批换根不会变红的断言。本 BET 只做这两样前置，不碰改道。

## 2. 实际发生了什么

三条纠偏都在，但**两条结论被实测推翻，一个新缺陷在过程中才现形**：

- 我按 job 名 `grep ~/Library/LaunchAgents` 判 foundry 未装机 —— 结论碰巧对，判据是错的。
  真实 `Label` 是 `com.omostation.knowledge-foundry`，job 名多带 `-6h`。改用真实 label 复核才成立。
- 我按 spec 初稿写下"`bin/scheduler-compile.py` 消费这两个字段"。实测它**根本不读 `reality`**，
  真正的消费者是 `bin/panorama/panorama-collect.py`；而 `status` 才是 scheduler-compile 读的那一个。
  契约里的这句是在动手后被否证的，我改了契约并重算 digest、拆掉旧 run 重建，没有将就用。
- 两条 panorama 记录各带**两个** `reality` 键，`yaml.safe_load` last-wins 把读者锁死在
  `pending` 上。所以任务从"改三个值"变成"删掉被遮蔽的键，再写唯一真值"——
  只改一行等于没改。
- refresh 那条 2026-09-30 的降级理由（"services.yaml 声明 enabled=false"）经查是**误读**，
  授权面写的是 `enabled: true`。机器面与授权面同向，我撤了那条 `ssot_conflict`。

## 3. 因此改变了什么

- registry：3 条纠偏 + 2 处重复键删除 + 2 条已收敛 `ssot_conflict` 撤键；launchd 登记集 12 → 13。
- `tests/unit`：13 处 host 字面量 → 0，三文件各带反字面量自锁。
- 新增 `test_cron_registry_reality_invariants.py`：I1/I2/I3 + 检测器自证 + `safe_load` 反证。
- 台账/spec 之外，本 retro 与 receipt 记下 4 条后续 BET，其中一条直接影响 B4b：
  **只按一个面枚举会漏掉 20+ 条活 job，"43 plist" 是下界**。

## 4. 教训（写进协议层的那几条）

1. **按名字探针 launchd，要分清 name 与 label。** `.omo/cron/registry.yaml` 的 `name` 不总等于
   plist `Label`；8 条 launchd job 干脆没有显式 `label` 字段，靠 `com.omostation.{name}` 合成。
   判据：任何"装没装"的结论必须用真实 Label 查，且把 name≠Label 的差值写进 note。
2. **"字段被谁消费"要用测量而不是引用措辞。** 我引用了自己上一轮写的 spec 句子，
   而那句话没被验过。一个没有枚举校验器的自由文本字段，消费者清单只能 `rg` 出来。
3. **重复键是 YAML 面的静默失效家族。** `safe_load` 不报错、不告警，只留最后一个。
   凡是"从 YAML 取真值"的门禁，若该文件由多方 hand-edit（本仓 registry 正是），
   就必有一条 dup-aware 断言；且它必须自带合成违规样本自证，并配一条"`safe_load` 看不见"的反证。
4. **降级理由也可能读错授权面。** 双向纠偏意味着"上修"也是候选方向；
   只朝"让 pytest 绿"的方向收敛，会把误读的降级永久化。
5. **不要用 `__file__` 派生被测对象的根。** 它会在 worktree 里必红，且因为是"派生的"而显得可信，
   比它替掉的字面量更危险。根要从被测文件自己的声明里取。
6. **反字面量自锁会被自己触发。** needle 写成整串就命中断言那一行本身；分两截拼接。
