# BET-Y1Q3-T10-51 retro

本文件记录 canonical `mcp.agora` 7433 端口契约修复。实现完成后补齐五问、
启动环境验证、回滚路径和 host runtime 未变更证据。

## 实施结果（2026-08-29）

- 根因：`mcp.agora` 的 SSOT/liveness 使用 7433，而 Agora SSE 默认环境值
  为 7431；原 Service Gateway 未传递服务声明的 `environment`。
- 修复：复用已有 `environment` 字段声明 `AGORA_MCP_SSE_PORT=7433`，并在
  所有 Service Gateway 子进程启动路径中构造 child-only environment；父进程
  环境不被修改，Agora standalone 默认 7431 不变。
- 验证：`tests/test_ops_cli.py` 为 `23 passed`；dry-run 仍输出
  `uv run --directory projects/agora agora-mcp --sse`；实测 child env 为
  `7433` 且 parent 未携带该变量；`py_compile` 与 ledger lint 通过。
- 未执行 `ops up`，未写入或加载 host plist，未启动服务进程；运行态 canary
  仍需独立 operational 活动。

1. **根因**：`mcp.agora` SSOT/liveness 使用 7433，而 Agora SSE 默认环境值
   为 7431；原 Service Gateway 未传播声明的 child environment。
