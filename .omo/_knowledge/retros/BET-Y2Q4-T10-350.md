## 4. 教训（lessons）

1. **squash 合并的子模块，gitlink 只能指 squash 产物**。`gh pr merge --squash --delete-branch` 之后
   源 commit 不在 main 祖先链上（实测 `merge-base --is-ancestor 791c977 origin/main` = NO）。
   固化位置候选：`AGENTS.md §6 子模块 commit 三步走` 的后置检查 —— 但更该落在 harness：
   `submodule-pointer-transaction.sh` 的 reachability 已能兜（本次 PASS 即证明它有效），无需新规则。
2. **门禁 FAIL 的原文必须先落盘再看**。`<gate> | tail -N` 同时毁掉判据行与退出码（本次两条都踩）。
   属既有「仪器阴性先证其能跑」「判据报警先 print 原始行」家族的新实例 —— 不新开条目，
   登记时并入该簇。
3. **`rg -rl` 复发了**，尽管文字固化早已在册（本次伪造出 `import l` 这种符号）。
   ⇒ 证据：纯文字层固化对高频误用无效，需要 harness 层拦截（别名/包装 `rg`）。这属
   「判据必须接线」的同一待裁族，交 principal，不自行开面。
4. **外部 `PYTHONPATH` 在 pytest rootdir 有 `pythonpath=["src"]` 时不是权威**。第一次变异证明
   因此假绿。判据：跑变异前后各打一次 `module.__file__`，不一致即装置失效。
5. **收口轴的诚实边界**：`operational.PROVEN` 的 canary 取自 `origin/main` 的 pin 检出，
   不是规范主检出；canonical 未同步 ⇒ 运行面仍是旧码。这条写进收据「未执行动作」而不是被
   PROVEN 掩盖 —— 代理量顶替真实量是 D1 红线。
