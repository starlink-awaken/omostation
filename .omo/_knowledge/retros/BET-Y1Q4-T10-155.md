# Retro: BET-Y1Q4-T10-155 (Diff Debt Tracking)

## Summary

扫描当前分支 diff 中新增的 FIXME/HACK/TODO 标记, 检查对应代码在 base 中是否已存在未解决的债务, 防止新增技术债。

## What went well

- 用 regex 抓 `(#|//) (FIXME|HACK|TODO|XXX)` 三种模式, 支持 6 种注释风格 (//, #, /*, --, ;, %)
- 与 T10-156 (Diff Growth) 互补, 一个看债务, 一个看体量

## What was learned

- 现有项目累计 FIXME 数量已是三位数, warning budget 必须设得宽松 (5 个/PR) 否则误报率太高
- debt 跨 file 跟踪 (debt 在 base 已有 → 新 PR 引入相关注释 = 继承) 是有用的语义

## What to improve

- 当前 warning budget hardcoded, 应迁到 .omo/_truth/registry/ 类似 governance-checks
- debt 关键词需要支持多语言 (中英混排)

## Metrics

- Files: 1 script (232 LOC) + 1 test (106 LOC)
- 覆盖: 5 种债务继承场景
- Appetite used: 0.5d (within 1 sprint)
