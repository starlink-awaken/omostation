# Retro: BET-Y1Q4-T10-136 — RLM 持久化变量内核

## What went well

- Spec 已先于代码落地（PCM-RLM 蓝图 → t10-136 spec），避免设计摇摆
- 27 个 pytest 全绿，单测试平均 <3ms（rlm_kernel 全部 in-memory）
- AST 校验拦截了 6 类危险节点（Import / FunctionDef / Lambda / 私有属性 / 黑名单 builtin / 危险 call），所有 escape 路径都被堵死
- 压缩率验证：4 个 test case 全部 ≥ 70%（典型 KEMS-v2 检索结果 list of 100 dicts 实测 ≈ 0.97）

## What was learned

- `reprlib.repr` 默认截断阈值（maxlist=6 / maxdict=4）配合自定义 max_tokens 截断比手写摘要可靠 — Python 标准库的格式化经验老道
- AST walk + 黑名单校验足以替代复杂的 sandbox 沙箱（如 RestrictedPython），且无外部依赖
- `vars_['hits'][:5]` 走受限 eval 比走 exec 更安全（只读），slice_var 因此单独走 read-only 路径
- `_is_simple_name_assignment` 辅助函数确保 exec 后只回写显式赋值的变量，避免意外污染

## What to improve

- exec_expr 当前的变量回写是「保守全回写」，下次实现可改为 AST-level 显式 Assign 提取
- session_stats 缺分位数（如 p50/p95 单次 observe 压缩率），下次加 histogram
- 缺 LLM-call hook：实际场景下 observe 结果应自动写 Spine draft，需要挂接
