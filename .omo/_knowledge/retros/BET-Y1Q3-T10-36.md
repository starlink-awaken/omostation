# BET-Y1Q3-T10-36 retro

Counting every Documents path as an executor made the audit unusable after the
Workspace owner migrations: read-only owners were indistinguishable from live
Documents writers. The new mode fields preserve the full reference inventory
while making `forbidden_executors` a precise operational metric.

The first live run exposed 3 real operational executors and 180 gateway
instructions. The distinction is intentional: the former require runtime
cutover/rollback evidence; the latter require declaration cleanup and must not
be silently discarded.
