# Retro — BET-Y2Q4-T10-290 FIB-02 投影时间语义

读数 base：工程腿 `origin/main = 3349250e8435c0f175da7eb3d29f01d48c9da036`（PR #5071 squash，
`2026-11-06T03:56:01Z`）→ 收口腿起手 `origin/main = 054c52eec`（#5073 之后）。收口腿在
`/Users/xiamingxing/ws-t290-closeout`（分支 `agent/governance-agent/t290-closeout`）撰写；
定向测试复跑在 `2f52fccbe` 那棵与 main 内容等价的检出 `ws-t289-finalize`。

## 1. 本意

投影服务租约、绑定内容的最后观测时间、当前文件副本时间，是三件不同的事。改前它们在人读的
那一屏上是混的：续租会把旧内容显示成新鲜，`cp` 出来的副本时间会被当成数据观测时间。本条要把
三者拆成三个独立字段 + 独立状态，且缺值必须是 `UNKNOWN`，不许用 `now` 或 `0` 伪造观测。
边界一条不许动 —— 内容新鲜度的 300 秒 TTL、revision/manifest/code 摘要身份、`CODE_DRIFT`
与各类 fail-closed。

## 4. 教训

1. **「mergeable ≠ 已投放」与「已投放 ≠ 本轮投放」是两件事**， operational 证据要分别指认：
   码面等同比对（sha256 逐字节）证明「生产跑的是这次交付的代码」，发布器日志证明「谁投的」。
   只看 PR `MERGED` 会得出「现网已生效」这个不成立的结论；只看 `runs` 增长会得出
   「本轮让它生效」这个更错的结论。
2. **反伪造类改动的验收证据，最好是一条真实存在的不一致**。本轮恰好赶上内容 15.4 h 未推进
   而租约持续续期，`VALID` + `STALE` 同屏 —— 这类读数无法由「加了字段就绿」的测试造出来，
   所以它比 70 passed 更承重。判据：能同时证「新副本」与「旧内容」的现网读数优先于夹具。
3. **台账落后于事实时，改记比补记危险**：必须同时断言两件事 —— 每个 evidence 位等于磁盘
   文件摘要、`content_digest` 等于 spec 字节摘要。只断言前者就会把规范绑定一起改（AGENTS.md
   §7「刷新台账里的文件摘要必须按字段路径定位」）。本轮脚本按这两类路径分别枚举，未用
   「块内出现即候选」的值匹配。
4. **`pytest` 装置漏 `pytest-timeout` 的失败形态是「没跑」**，不是「跑红」：`pyproject.toml`
   注入 `--timeout=300`，最小 venv 里没有该插件就 `error: unrecognized arguments`，
   计数 0 条用例。判据：hermetic 复跑收尾必须看到 `N passed`，`usage:` 行等于装置没搭对。
