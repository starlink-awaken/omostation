# BET-Y2Q4-T10-211 Closeout Retro

## Intended

在不改变 `release` 删除护栏的前提下，为 dirty root、dirty submodule、PASW 残留和无法读取的 worktree 提供只读分类诊断。

## Happened

- 新增 `release-diagnose <session>`。
- clean 返回 0；发现残留返回 1；worktree/元数据不可读返回 2。
- 诊断只读取 Git 状态，不执行 reset、stash、clean、remove 或 branch delete。
- focused shell tests 覆盖 clean、dirty root、dirty submodule、missing session。
- 生命周期回归测试 30 项全部通过。
- `make gac-local-gate` 未通过，原因是隔离工作树的 pinned 子模块不完整：缺少 cockpit-ui 构建产物、Cockpit/Agora/ECOS 文件以及 OMO workflow packet compiler；这些不是本次变更引入。

## Changed

- 将 release 前的手工排查步骤固化为一个确定性入口。
- 保留现有 `release` 分支逻辑不变。
- 发现 PASW 失效目录时给出 `remove-stale-metadata` 建议，不自动删除。

## Lessons

1. 诊断命令必须保持只读；修复动作继续留在显式 release/repair 流程中。
2. 需要区分“诊断实现通过”和“完整仓库门禁可运行”；隔离工作树缺失子模块时，后者只能如实记录为 blocked。
3. `agent-workflow start` 在 pinned OMO 子模块上被 `WORK_PACKET_COMPILER_UNAVAILABLE` 阻断，说明工作树创建需要先验证 OMO workflow runtime 可用性。
