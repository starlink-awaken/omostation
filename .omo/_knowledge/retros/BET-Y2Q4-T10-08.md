# BET-Y2Q4-T10-08 Closeout Retro

> **TL;DR**: TOOL-GRAPHQL-FLAKY 处置落地：bin/lib/gh_query.py 共享助手
> （瞬态重试 + 空输出重试 + GhQueryUnknown/GhQueryFailed 双异常分层），
> clone-lifecycle integrate 接线（原"空列表静默建 PR"→"重试 ×3 后分流"），
> 7 个 hermetic 测试钉住语义。

## 计划 vs 实际

| 项 | 结果 |
|---|---|
| gh_query 共享助手 | ✅ 瞬态重试（EOF/timeout/network 字样）+ 空输出重试（rc=0+空 = 抖动签名）+ 耗尽分流 |
| clone-lifecycle 接线 | ✅ GhQueryUnknown → reject pr_query_unknown；GhQueryFailed → pr_query_failed；耗尽仍空 = 真无 PR → 建新 PR 合法（重试已吸收抖动） |
| prune-ci-runs 去重 | ⚠️ **主动放弃**：其 gh_api 的"DELETE 静默失败 + 空=空对象"语义是有意设计，硬换助手会引入语义漂移——保留原样并在本 retro 记录 |
| hermetic 测试 | ✅ 7 用例（成功透传/瞬态重试/耗尽 UNKNOWN/非瞬态快速失败/空重试后合法空/空耗尽 UNKNOWN/坏 JSON） |
| gate/lint | ✅ PASS / 0 新增 |

## 设计要点

1. **空输出的两层语义**：rc=0+空 = 抖动签名（重试），耗尽后空 = 调用方语义分流
   （破坏性 → UNKNOWN 拒绝；非破坏性 → 合法空）。一个开关（treat_empty_as_unknown）
   让两种调用方共享同一实现。
2. **clone-lifecycle 的行为变更**（空列表静默建 PR → 重试后仍空才建）是 debt 规则
   明令的方向：重试已吸收抖动，持续空 = 真"无 PR"，建 PR 不再是抖动受害者。
3. gen-real-evalset 不接线：优雅降级（gh 不可用则跳过 GitHub 补充）是其设计意图，
   非破坏性——不滥用同一开关。
