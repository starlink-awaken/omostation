current launchd observation window, so the projection reflects exactly one
current run and malformed current records still fail closed.

## Changed / Lessons

- The launchd-scheduled collector path is the live projection source; a merge
  alone does not change the host until the scheduled tick runs against deployed
  bytes — host-sync verification belongs in the closeout evidence, not only in
  CI.
- Prior-attempt filtering must key on the current run identity, not wall-clock
  windows alone; malformed current-run records must keep failing closed.
