## 4 lessons

1. **dataclass + importlib 在 py3.14 的 bug**: 用 `importlib.util.spec_from_file_location` 加载含 `@dataclass` 的模块会触发 `cls.__module__` 为 None. 解决: `exec(compile(source, path, "exec"), mod.__dict__)` 绕过 spec.
2. **win-take-all 在单进程测试有限制**: 两个独立 controller 各自有 lock, 都会 grant takeover. 真实部署需用 file lock 共享. 测试中用 audit log 验证两个 event 都记录来表达.
3. **size-based rotation 必须先 read 再 write**: 1MB 阈值检测后, rename 旧文件 .jsonl.1 → .jsonl.10, 移出当前 .jsonl 才能重新 append. 否则下次 fcntl 锁住会死锁.
4. **pytest rootdir 自动推断**: 从 `projects/omlxc/tests/integration/` 跑测试, rootdir 自动设为 `projects/omlxc/`. `parents[N]` 计算要小心.
