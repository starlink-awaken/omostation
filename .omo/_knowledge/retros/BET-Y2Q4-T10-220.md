## 2 happened — 实际发生了什么

写侧四个 bin 写点 + 内核三个站点全部改道，读侧 8 个读点接进新加的
`repo_root.state_file_read()`；R-GOV-2 跨键复制删除、阈值与 WARN 分级不动；
`write-owners` 收成单写者并维持 `present == declared == 23`。
C1–C3 既做成了 hermetic 测试，也用真实 profile 复现了一遍（state 根落新值、检出逐字节未变）。

三处**初稿被实测否证**，都写进了 spec 而不是悄悄改掉：

1. **`id` 改指活入口会让判据自否证**。`script-registry.validate()` 用
   `registered = set(ids)` 且 `missing = actual_scripts - registered`，
   基线 PASSED 713。改 id 之后两个条目同 id 被 set 静默去重，而
   `bin/meta/compass_radar.py` 从 registered 消失 ⇒ `Missing registrations: 1`。
   于是本轮只做登记侧诚实化（description + `maturity: deprecated`），删除动作另立。
2. **裸 `git grep` 的 C8 判据会假绿**。单一形态只命中 4 处，漏掉分引号写法
   （`".omo" / "state" / "system.yaml"`）和 `omo_dir / "state"` 形态 ——
   那样一条判据在写者没改完时就变绿。换成 AST 扫 + 8 文件 allowlist 集合相等 + 反向核对。
3. **给 `worktree_dirty_count` 补写者会把 T10-219 的门禁变红**。守卫判据是
   `present == declared` 双向，而该键不在 HEAD 的 23 个键里。声明只能补齐"文件里已有的键"。

还有一次**检测器自己失效**：AST 用栈弹序拼 `/` 链得到 `"system.yaml/state"`，
于是那条源码扫描守卫对任何代码都绿 —— 而且它"通过"了。补一条合成违规样本自证会咬。

两条 `tests/unit` 红看起来像我引入，实测归 #4524：摘库让"回退到最后提交的 legacy 路径"
这条**前置断言**失效（`health.yaml` 已不被 track），而 CI 的 pytest 白名单不含 `tests/unit/**`。

## 3 changed — 改变了什么

- `.omo/state/system.yaml` 现在有两个身份：**检出的 = 最后提交快照（继续 tracked）**，
  **state 根的 = 运行态**。读者 state 根优先、检出兜底；未声明 profile 时解析恒等。
- `health_score_evidence` 的语义归一：只有 `evidence-smoke` 写它，
  `compass_radar` 不再冒充。R-GOV-2 的 divergence 现在是真值，不再恒为 0。
- `repo_root` 多了 `state_file_read()`，与 `projection_read()` 并列但**不共用注册表**。
- 内核侧 `omo_ingress.write_system_projection_fields` 成为 system.yaml 的唯一落笔点，
  `omo_state` 的两处退回调用方本位。
- 子模块 gitlink：`56cfc5b → 1eda1fde7`。

## 4 lessons — 固化什么

1. **摘库动作改变的是"读者兜底测试"的前提，不是只有文件位置。** 把某件产物从 git 摘掉，
   任何形如"找不到 canonical 就回退到最后提交的那份"的测试断言当场失效。
   判据：改跟踪状态后，`git grep -l "falls back\|兜底\|回退"` 逐个跑一遍，别只跑新写的测试。
2. **CI 的 pytest 文件白名单是一层可见性边界**（`governance-check.yml:118-126`）。
   `tests/unit/**` 不在里面，所以那里的红永远不会挡 PR。本地判据不能只报"CI 绿"。
3. **任何源码扫描守卫必须先对一个合成违规样本证明它会咬。** 递归按源码顺序展开 `/` 链，
   不是栈弹序；否则守卫静默为真，且它的"通过"看起来和真通过一模一样。
4. **判据要跑一次再写进契约**。本轮三次初稿否证都是同一个形状：
   想象中的工具行为（`validate` 会拒绝重复 id / `grep` 能扫全 / 声明补齐就行）
   与实际集合语义相反。写 done_when 前先跑那条命令。
5. **只改 caller 不改写点是假修复。** 普查要问到"谁最后落笔"，
   否则 `write_surfaces` 和门禁都会显示"改完了"，而行为一点没变。
