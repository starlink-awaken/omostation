# BET-Y1Q3-T10-16 复盘

## 北极星

消除 monitor/heartbeat 角色每 2min 纯空转：三缺口叠加（daemon 未注册 alert/heartbeat handler + resident-routes.yaml 无 system.health/governance:gate_failed/alert/heartbeat/system.alive 规则 + 统一事件流无 monitor/heartbeat 事件类型），observability 平面 456 条 258 critical 从未进事件流。本次把 monitor/heartbeat 升级为角色私有 tick（publish→路由→处理），让告警外发与活性台账真正走统一事件流。

## 做了什么

- **`omo/resident/heartbeat.py`（新增）**：`register_with_daemon` 注册 heartbeat handler（safe）；`publish_heartbeat` 调 status.snapshot 生成 `system.alive` 事件 → 追加统一事件流 → 路由 → 幂等沉淀 `.omo/state/resident-heartbeat.jsonl` 活性台账
- **`omo/resident/monitor.py`（新增）**：`register_with_daemon` 注册 alert handler（safe）；`publish_monitor` 增量读 observability `severity∈{critical,degraded}` → 生成 `alert` 事件 → 追加统一事件流 → 路由 → 调 alert-connectors deliver 外发（复用 T10-14 alert.py），**fail-closed**（无 webhook 配置返回 False 不崩溃）
- **`daemon.py`**：`_register_default_handlers` 增补 monitor/heartbeat 两模块；`run_daemon` per-role publish hook（tick_once 后 publish，本 tick 消费上一 tick 发布，2min 节律）
- **`resident-routes.yaml`**：新增 `alert→alert` / `system.alive→heartbeat` 两条规则（safe: true）
- **`install-resident-cron.sh`**：移除 `CRON_ALERT`（--dry-run），告警外发唯一路径 = daemon monitor 角色承担
- **测试**：新增 test_resident_heartbeat.py / test_resident_monitor.py 单测 + 集成测试扩展，23 个 resident 测试全绿
- **真实链路验证**：heartbeat.publish 实跑 → events.jsonl 出现 system.alive → daemon --role heartbeat → 活性台账追加 4 条幂等（health=recovered）；monitor.publish 实跑 → observability critical/degraded → events.jsonl 出现 alert → daemon --role monitor → deliver fail-closed（delivered=False）沉淀台账

## 没做什么

- 不接 alert-handler.py（OBS-02 governance-alerts 主动引擎，独立体系后续评估）
- 不实现 monitor 对 governance:gate_failed 的主动探测（observability 有事件才转发）
- 不改 signal-poller.py / status.py 既有逻辑

## 教训

- **done 的 completion_evidence 必须 outcome_accepted**：bet-done-transition check 是 diff-scoped（只对本次从非 done 变 done 的 BET 校验），T10-13 的 evaluating 是遗留债务不可参照。value 轴 ACCEPTED 硬性要求人类 SSH 签名 attestation（`ssh-keygen -Y sign`，allowed-signers 复验），agent 无法代签伪造。
- **勾选 spec 验收 checkbox 会改变 content_digest**：spec 文件 sha256 变化后台账 `accepted_specifications[].content_digest` 必须同步更新，否则 SPEC_DIGEST_MISMATCH。
- **evidence 引用不能指向 gitignored 产物**：`.omo/state/*.jsonl` 是运行时台账（gitignored），CI checkout 后不存在 → 引用必须落在非 gitignored 的已提交文件（代码/测试/attestation/retro）。
- **ruff CI 版本对齐**：CI lint 用 `--with "ruff>=0.4"`（解析为 ruff==0.16.4），本地须同版本 `ruff format` 否则 3 文件 would be reformatted 拦 CI。
