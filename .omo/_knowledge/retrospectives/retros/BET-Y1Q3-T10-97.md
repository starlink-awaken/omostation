# BET-Y1Q3-T10-97 retrospective

## Q1. What was intended?

Restore completion-evidence integrity for T10-02 and T10-06 after their
canonical scorecard file changed.

## Q2. What happened?

The baseline audit found exactly eight stale scorecard digests. Updating only
those references made both matrices derive their pre-existing
`outcome_accepted` state again; no execution or value semantics changed.

## Q3. What was discovered?

Completion evidence is content-addressed and can drift when a shared helper
changes. A green historical BET becomes unverifiable until its references are
reconciled against the current canonical bytes.

## Q4. Surface accounting

The repair changed eight YAML digest scalars and added four T10-97 evidence
surfaces. It changed no source code, evidence payload, Documents content,
runtime state, status, attestation, or value sample.

## Q5. What should the next agent know?

When shared governance helpers change, run the ledger verifier against the
current mainline and repair only exact stale references. Never use a recursive
BET self-verification command in a BET's own verify list.
