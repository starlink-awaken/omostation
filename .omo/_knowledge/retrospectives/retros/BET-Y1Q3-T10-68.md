# BET-Y1Q3-T10-68 retrospective

## Q1. What was intended?

Prevent recoverable Workspace quarantine packages from being mistaken for
disposable untracked output.

## Q2. What happened?

The public-runtime package disappeared after a successful postflight because
the target directory was not protected from ordinary repository cleanup. No
payload recovery is claimed here.

## Q3. What went well?

The retention failure was reproduced with `git check-ignore` before repair. The
fix is a narrow ignore rule with a direct regression test.

## Q4. Surface accounting

One root ignore rule, one regression test, one report, one spec, and one retro
were added. Documents and runtime payload bytes changed by zero in this BET.

## Q5. What changes next?

Recover or recreate the public-runtime rollback package only through a fresh
human-gated transaction after confirming the new retention rule. Keep all
family statuses non-terminal until that receipt exists.
