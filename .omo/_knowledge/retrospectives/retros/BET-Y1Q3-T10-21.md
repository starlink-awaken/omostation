# BET-Y1Q3-T10-21 复盘 — L4 / Documents / Agora 单实例收敛架构基线

## Q1 — 目标与结果

目标是固化唯一 canonical L4、Documents 内容平面与 Workspace 执行平面边界，并把 Agora nested L4 纳入可验证的身份、路由、隔离、迁移和长期运维治理。架构、设计 Spec、实例盘点和既有 Documents convergence plan addendum 已完成；没有删除 nested L4、切换生产路由或移动用户内容。

## Q2 — 做对了什么

- 识别出 `projects/l4-kernel` 与 `projects/agora/projects/l4-kernel` 是同源但不同版本的两个真实实例，而不是普通目录重复。
- 以 `ManifestRegistry + Content Plane + T0-T8 Harness` 作为 canonical L4，保留 Agora nested L4 为待 cutover 的回滚材料。
- 将 Documents、L4、Cockpit、OMO、Runtime、Kairon/KOS、Agora 的 owner 和数据流写成稳定架构约束。
- 使用独立 clone、affected-graph receipt、路径 claim、精确提交和 tag，未污染共享 Workspace。
- 修复设计资产新增后暴露的 `docs/downloads` 索引缺口，使 doc-ssot-lint 从 1 conflict 变为 0 conflict。

## Q3 — 失败与根因

- 首次 BET 注册 patch 锚定了文件中间的第一个 `depends_on`，使旧 BET 字段暂时错归新 BET；YAML 解析未能及时阻止，随后通过 entry 边界检查恢复。
- 首个 closeout 缺少 retro 文件，被 vision→retro chain 正确阻断；补齐复盘路径后旧 run 因 WorkPacket source drift 关闭，重新 start 生成了完整 packet。
- 独立 clone 初始未加载完整子模块，workflow 和全局 gate 分别暴露 import/dependency 闭包问题；后续只初始化必要 ECOS/OMO 子模块，未在共享树修复。
- 历史台账仍有 completion evidence drift；本 BET 不扩大范围清理历史债务。

## Q4 — 表面积与风险

本 BET 新增 5 个架构/证据/计划文件和 1 个导航指针修复，目标是降低后续跨仓误路由和 Documents 执行面漂移。残余风险是 Agora 仍包含 nested L4、生产 route 尚未切换、Documents 仍有 runtime/cache、双实例 canary 尚未执行。风险通过 non-goals、canonical identity、consumer scan、rollback 和分波次 gate 控制。

## Q5 — 下一步与反证

下一波应在独立子仓/跨仓 BET 中实现 Agora canonical route，并验证 `l4_instance_id`、commit、registry digest、tool profile 和 Documents/Runtime root 的一致性。若出现 route ambiguity、identity mismatch、root overlap、consumer 未清零、T8 违规增加或 rollback 缺失，必须停止 cutover；在此之前不得删除 `projects/agora/projects/l4-kernel`。
## Follow-up registered

The architecture follow-up registered T10-41 to govern the remaining
Documents execution/cache retirement. The key decision is capability-based
classification: content and read-only references stay in Documents, while
Workspace owns execution, state, caches, schedules, indexes, and runtime
evidence. Physical deletion remains a separate human-gated decision.
