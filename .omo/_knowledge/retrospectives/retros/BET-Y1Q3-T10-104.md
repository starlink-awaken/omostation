# BET-Y1Q3-T10-104 retrospective

## Q1. What was intended?

Remove active ZCode client state from Documents while preserving continuity,
rollback, and a stable full-tree L4 audit.

## Q2. What happened?

The initial Workspace runtime target passed restart verification and was then
externally purged sixteen seconds later. The open desktop index could not be
reattached under macOS hardened runtime. The healthy CLI database, native seed,
settings, logs, and agent configuration were preserved before shutdown. ZCode
was rebuilt and restarted from durable App Support with active target handles,
143 desktop tasks, and the durable CLI message store.

## Q3. What changed in the design?

Client state is not a Workspace capability. Code, CLI, policy, tests, manifests,
and reports belong to Workspace; long-lived third-party application data belongs
to native App Support. Healthy migrations now use copy, verify, restart, and
finalize instead of move-first. The Documents source remains the rollback copy
until target handles are proven.

GaC also rejected a dedicated new `bin/` wrapper. The final implementation
deepens the existing registered ZCode config owner, preserving entry-point and
subtraction convergence.

## Q4. What was learned?

- A green immediate canary does not prove storage-class durability.
- Open SQLite descriptors can mask unlink damage; link count and delayed
  re-verification matter.
- Recovery evidence must separate content preservation from index equivalence.
- Shell variables such as zsh `path` must not be reused in diagnostics.
- When the deleting process cannot be attributed, mark it `UNPROVABLE`; fix the
  proven architecture fault and retain monitoring.

## Q5. What remains?

Exact pre-purge desktop snapshots/checkpoints were not recovered. Documents
still contains unrelated runtime/cache/archive/symlink debt, and public-runtime
and root-oneoff evidence gaps remain. Principal-bound value is `NOT_PROVEN`.

Final implementation is reachable from root main at
`8737b24a14e2de4ca68116a3f5b52f4e2c905c18`. Required CI, mainline live replay,
delayed durability, consumer audit, focused tests, and GaC pass. The known-loss
boundary remains unchanged.
