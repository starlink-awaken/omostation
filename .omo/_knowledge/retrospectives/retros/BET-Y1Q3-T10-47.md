# BET-Y1Q3-T10-47 retro

The mainline GaC gate exposed a deterministic environment seam: the installed
Homebrew-generated plist files use `/opt/homebrew/bin/python3`, while the
generator under `uv run` scanned PATH after excluding uv paths and selected
`/usr/bin/python3`. This BET isolates the repair to stable interpreter
selection; it does not rewrite host plist files or change service semantics.

The regression test first reproduced the failure under a uv-like PATH
(`/usr/bin/python3` won over the installed Homebrew plist identity). The
generator-only repair now selects `/opt/homebrew/bin/python3` deterministically;
focused tests pass 5/5, validate and check report zero errors/drifts, and the
full default GaC gate passes all 57 executed checks. The four host plist hashes
were unchanged before/after verification. No host service or plist mutation
was performed.
