# .omo — 运行态与治理真值目录

## 作用

`.omo/` 存放治理与运行态的事实基线：SSOT 注册、状态快照、治理面规则、治理运行数据等。
这是仓库治理系统的真值入口，不是业务代码实现区。

## 编辑规则（精简）

- 阅读根仓 [`../AGENTS.md`](../AGENTS.md) 与该域相关 SSOT 文档。
- 非关键路径改动优先走治理/CLI 管道，不直接改写运行态核心文件。
- 涉及 registry/状态文件变更需补齐审计与 closeout 证据。

## 快速入口

- 真值与面规则：`.omo/_truth/`
- 状态同步：`.omo/state/`
- 治理事件与投影：`.omo/_control/`、`.omo/_data/`
