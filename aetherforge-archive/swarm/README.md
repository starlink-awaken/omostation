# AetherForge Swarm [LIBRARY-ONLY]

> **Note:** This package is **[LIBRARY-ONLY]**. 
> It does not expose any standalone HTTP servers, daemon processes, or CLI entrypoints. Multi-agent orchestration, bidding, and DAG execution workflows are invoked exclusively via Agora BOS URI (`bos://capability/swarm/*`) or orchestrated by the L2 MetaOS workflow engine.

## Overview

AetherForge Swarm is a decentralized multi-agent execution framework built around economic ledgers, token bidding, and dependency-graph task execution.
