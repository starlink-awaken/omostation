# gbrain API / Usage Reference

> Quick reference for using **gbrain** programmatically and from the command line.

## Command Line

- `bun install` — install deps
- `bun test` — run tests
- `bun run build` — build

## Programmatic API

See source exports in `src/index.ts` or package README.

## Configuration

- Stack: typescript
- Dependencies: see [`../pyproject.toml`](../pyproject.toml) (Python) or [`../package.json`](../package.json) (TypeScript).
- Environment variables and ports: see workspace `protocols/port-registry.yaml` and root `.env.example`.
