# GBrain 能力地图

> Postgres 知识数据库 · 混合 RAG 搜索

---

## 一、架构定位

```
┌─────────────────────────────────────────────────────────────┐
│                    GBrain — 知识数据库                        │
├─────────────────────────────────────────────────────────────┤
│  Postgres 存储  │  混合 RAG  │  MCP 工具 (见 project-registry.yaml: gbrain)  │  知识图谱   │
│  Native DB     │  Hybrid   │  MCP Tools   │  Graph        │
└─────────────────────────────────────────────────────────────┘
```

---

## 二、核心功能

| 功能 | 说明 | 测试数 |
|------|------|--------|

## 四、CLI 命令

```bash
gbrain search "关键词"    # 搜索
gbrain status             # 状态
gbrain index              # 索引
gbrain graph              # 图谱
```
