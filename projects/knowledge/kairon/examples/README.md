# Examples

This directory contains runnable examples for `kairon`.

## Layout

Each subdirectory is a self-contained example. See the `README.md` inside each example for instructions.

## Running Examples

Most examples assume the workspace has been cloned recursively:

```bash
git clone --recursive https://github.com/starlink-awaken/omostation.git
cd omostation/projects/kairon/examples
```

Then follow the individual example README.

## Contributing Examples

Have a useful example? Open a PR! Keep examples focused, well-commented, and include a short README explaining what it demonstrates.
