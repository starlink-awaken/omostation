# DigitalBrainOS Skill

Use this skill when a task involves DigitalBrainOS strategy, architecture,
project-set coordination, multi-agent work, object model design, governance, or
future integration across the workspace.

## Trigger

Use this skill for requests containing:

- DigitalBrainOS
- digital brain
- second brain
- 多 Agent
- 多项目协作
- project-set
- object model
- runtime API
- governance
- work packet
- SharedBrain / KOS / Minerva / Sophia / Agora / eCOS integration

## Workflow

1. Read `README.md` or `README.zh-CN.md`.
2. Read `AGENTS.md`.
3. Read the active work packet if present.
4. Classify the task:
   - strategy
   - architecture
   - object model
   - governance
   - integration
   - implementation
   - evaluation
5. If the task is non-trivial, create or update a work packet.
6. Declare write scope before editing.
7. Execute.
8. Validate.
9. Update handoff notes.

## Output Requirements

Every response should state:

- changed artifacts
- validation performed
- risks or unresolved questions
- recommended next work packet
