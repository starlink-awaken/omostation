# Skill: Integration Review

## When To Use

Use before Conductor integrates Agent output into canonical docs, schemas, code,
or plans.

## Read First

1. Source artifact.
2. Active work packet.
3. Relevant acceptance criteria.
4. Governance notes if any.

## Steps

1. Confirm artifact path and source agent.
2. Check scope compliance.
3. Check evidence quality.
4. Check conflicts with existing canonical docs.
5. Decide accept, revise, reject, or escalate.
6. Record integration note.
7. Validate after integration.

## Outputs

- Integration decision.
- Changed canonical artifacts if accepted.
- Rejection or revision reason if not accepted.

## Forbidden

- Do not integrate output without source path.
- Do not integrate output outside write scope.
- Do not suppress conflicts.

## Validation

Integration review is valid when the Conductor can explain why the output was
accepted or rejected.
