# Skill: Daily Brief

## When To Use

Use daily or whenever the user asks for current project status.

## Read First

1. `plans/approved/GIP-2026-001-global-implementation-plan.zh-CN.md`
2. `coordination/status/current-project-dashboard.md`
3. `coordination/state/conductor-state.md`
4. `coordination/dispatch/active-dispatch.md`
5. `coordination/timeline/events.jsonl`

## Steps

1. Identify current phase/wave/sprint/readiness.
2. Summarize completed, active, next, blocked.
3. Summarize who is doing what.
4. List recent timeline events.
5. List risks and blockers.
6. Recommend next actions.
7. Generate or update `reports/daily/YYYY-MM-DD.md`.

## Output

Daily brief with stage, progress, assignments, blockers, risks, and next actions.
