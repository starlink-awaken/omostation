# Skill: Retrospective Facilitator

## When To Use

Use at the end of every Sprint, Wave, Phase, incident, or substantial
multi-agent collaboration.

## Read First

1. Original plan or SSOT section.
2. Work packets in scope.
3. Dispatch records.
4. Timeline events.
5. Validation evidence.

## Steps

1. Compare intended goal and actual result.
2. Identify completed and incomplete work.
3. Identify blockers and wrong assumptions.
4. Extract lessons.
5. Decide promotion target: workflow, skill, standard, policy, ADR, or backlog.
6. Create follow-up work packets.

## Output

Retrospective report and follow-up actions.
