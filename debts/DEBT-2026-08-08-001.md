### 根因
Phase 4 清理 cockpit_mcp.py 时，只删除了文件本身，未同步清理所有 import 引用点。删除前缺少影响面分析。

### 解决方案
1. **立即**: 清理所有残留 import，替换为 Agora BOS 调用
   - `workspace_context()` → `resolve_bos_uri("bos://cockpit/context")`
   - `cards_check()` → Agora BOS 调用
   - `cards_status()` → Agora BOS 调用
   - `vault_search()` → Agora BOS 调用

2. **短期**: 如果 Agora BOS 路径尚未就绪，恢复 `scripts/cockpit_mcp.py` 的极简 shim 版本

3. **长期**: 完成 Phase 4 迁移，所有 L4 bridge 命令改为通过 Agora BOS 调用
