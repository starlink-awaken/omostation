# cockpit CLI 代码缺陷 — events-watch AttributeError + audit 脚本路径硬编码错误

## 摘要
两个 P0 级别代码缺陷导致 cockpit 命令无参运行必崩：
1. `events-watch` 构造 namespace 时缺少 `url` 属性，导致 `AttributeError`
2. `audit` 脚本路径硬编码为 `bin/workspace-audit`，实际脚本在 `bin/ssot/workspace-audit`

## 详情

### D-1: events-watch AttributeError

**文件:** `src/cockpit/cli.py:761-763`

```python
"events-watch": lambda a: _c_events(
    __import__("argparse").Namespace(watch=True, limit=getattr(a, "limit", 20), topic=None)
),
```

**问题:** `_c_events` 内部调用 `run_events_dashboard(a.url)` (`cli.py:170`)，但手动构造的 `Namespace` **没有 `url` 属性**。

**触发:** `cockpit events-watch` → 必崩

**修复建议:**
```python
# 方案 A: 复用 events 子命令的 --url 参数
"events-watch": lambda a: _c_events(a),

# 方案 B: 在 _c_events 内做安全回退
def _c_events(a):
    url = getattr(a, "url", None) or f"http://127.0.0.1:{os.environ.get('AGORA_MCP_SSE_PORT', '7431')}/v1/events"
    run_events_dashboard(url)
    return 0
```

### D-2: audit 脚本路径硬编码错误

**文件:** `src/cockpit/commands/audit.py:33`

```python
WORKSPACE_AUDIT = WORKSPACE_ROOT / "bin" / "workspace-audit"
```

**实际位置:**
- `/Users/xiamingxing/Workspace/bin/ssot/workspace-audit`
- `/Users/xiamingxing/Workspace/scripts/bin/ssot/workspace-audit`

**问题:** 路径推算错误。`WORKSPACE_ROOT` 推算为 `_CLI_DIR.parent.parent.parent.parent` = `.../Workspace`，然后拼接 `bin/workspace-audit`，但实际脚本在 `bin/ssot/` 子目录。

**触发:** `cockpit audit` → `[Error] 找不到 /Users/xiamingxing/Workspace/bin/workspace-audit`

**修复建议:**
```python
# 修正路径
WORKSPACE_AUDIT = WORKSPACE_ROOT / "bin" / "ssot" / "workspace-audit"

# 或复用 base._find_cli()
from .base import _find_cli

WORKSPACE_AUDIT = _find_cli("workspace-audit")
```
